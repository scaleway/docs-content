## Create an encrypted volume

1. In the Scaleway console side menu, go to **Storage** > **Block Storage**. The Block Storage page opens.
2. Click **Create volume**. The creation wizard opens.
3. Choose the [Availability Zone](/instances/concepts/#availability-zone) of the Instance to which you want to attach your volume.
4. Configure the name, [IOPS](/block-storage/concepts/#iops), and size of the volume. See [How to create a Block Storage volume](/block-storage/how-to/create-a-volume/) for more information on these settings.
5. In the **Encryption** section, check **Enable volume encryption**.
6. Choose the key that encrypts your volume:
    - **Select an existing KMS key**: select a key from the **Select key** dropdown. The dropdown only lists symmetric encryption keys located in the same region as your volume.
    - **Create a new KMS key**: enter a name for the key. The name must start and end with alphanumeric characters, and only contain alphanumeric characters, dots, or dashes. The key uses symmetric encryption with the **AES_256_GCM** algorithm.
7. (Optional) Select an Instance from the dropdown to attach your volume.
8. Check the estimated cost, then click **Create volume**.

## Check the encryption of a volume

1. In the Scaleway console side menu, go to **Storage** > **Block Storage**. The Block Storage page opens.
2. Click the name of the volume you want to check. The **Overview** tab of the volume opens.
3. In the **Volume information** section, find the **Encryption** field. For an encrypted volume, this field displays the name and ID of the Key Manager key.
4. (Optional) Click the name of the key to open the key in Key Manager.
