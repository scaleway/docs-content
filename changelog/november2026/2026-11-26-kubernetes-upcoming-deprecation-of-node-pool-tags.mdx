---
title: Kubernetes Kapsule & Kosmos - node pool tags will no longer set labels and taints
status: deprecated
date: 2026-11-26
category: containers
product: kubernetes
---

From February 28, 2027, tags set on a node pool are no longer interpreted: labels and taints must use the native `labels` and `taints` fields. Existing tags are converted automatically on that date (no manual action required), and the `tags` field is not removed.
