**<u>Breaking</u>**

* Removed parameter `replace` on `DeleteNode` route, the route `ReplaceNode` should be used instead.


**Features**

* `ReplaceNode` route is not deprecated anymore.
* Cloud-controller manager version is bumped to `0.36.2`.

**Fixes**

* The values of the `min_size` and `max_size` fields are now pinned to `target_size` in the case of pools without `autoscaling`.
* `target_size` will always be within `min_size` - `max_size` range in the case of pools with `autoscaling`.
