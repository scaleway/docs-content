status: added
date: 2026-09-09

---

New asymmetric signature algorithms:

- ML-DSA-44
- ML-DSA-65
- ML-DSA-87

New key encapsulation algorithms: 

- ML-KEM-768
- ML-KEM-1024

New endpoints:

- Wrap a key using ML-KEM. For details, see the [API documentation](https://www.scaleway.com/en/developers/api/key-manager/keys#wrap-a-key).
- Unwrap a key using ML-KEM. All details available in the [API documentation](https://www.scaleway.com/en/developers/api/key-manager/keys#unwrap-a-key)
