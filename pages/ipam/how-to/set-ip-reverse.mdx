Reverse DNS is the opposite of classic forward DNS, and maps an IP address to a hostname. Setting a custom reverse DNS record is useful, for example, to improve the deliverability of emails sent from your server.

Scaleway IPAM allows you to set the reverse DNS of your public IP addresses:

- For an IPv4 address, you set one hostname for the address.
- For an IPv6 block, you set a hostname for each individual address within the block.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A public IPv4 address or IPv6 block, [reserved with IPAM](/ipam/how-to/reserve-ip/) or attached to a Scaleway resource
- A domain with an `A` record (for IPv4) or `AAAA` record (for IPv6) pointing to the IP address you want to configure

## Set the reverse DNS of an IPv4 address

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Select **Public zonal IPs** or **Public regional IPs** in the **Source** filter, and use the other filters that display alongside it to find the IPv4 address you want to configure.

3. Click the <Icon name="more" /> icon next to the IP address, and then click **Manage reverse**. A pop-up displays.

4. Enter the fully qualified domain name (FQDN) to associate with the IP address in the **Hostname** field, without any protocol (e.g. `mail.example.com.`, not `http://mail.example.com`).

5. Click **Save**.

## Set the reverse DNS of IPv6 addresses

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Select **Public zonal IPs** or **Public regional IPs** in the **Source** filter, and use the other filters that display alongside it to find the IPv6 block you want to configure.

3. Click the <Icon name="more" /> icon next to the IPv6 block, and then click **Manage reverse**. A pop-up displays.

4. Enter an address within the block in the **IP address** field, and the FQDN to associate with it in the **Hostname** field.

5. Optionally, click **Add another IP** to set the reverse DNS of other addresses within the same block, and repeat the previous step for each address.

6. Click **Save**.

## Reset the reverse DNS of an IP address

Resetting the reverse DNS of an IP address sets it back to its default Scaleway value (e.g. `35-58-232-78.rev.scw.cloud.`). For IPv6 blocks, the reset applies to all the reverse DNS records configured within the block.

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Select **Public zonal IPs** or **Public regional IPs** in the **Source** filter, and use the other filters that display alongside it to find the IP address you want to reset.

3. Click the <Icon name="more" /> icon next to the IP address, and then click **Reset reverse**. A confirmation dialog displays.

4. Click **Confirm**.

## Set reverse DNS via the IPAM API

You can also set the reverse DNS of your IP addresses with the [update an IP](https://www.scaleway.com/en/developers/api/ipam/#path-ips-update-an-ip) call of the IPAM API, for example to automate the configuration of multiple IPv6 addresses.

Replace `<ip-id>` with the ID of your IP address, and modify the payload according to the hostnames and addresses you want to configure.

<Message type="tip">
To find the ID of your IP address, use the [list IPs](https://www.scaleway.com/en/developers/api/ipam/#path-ips-list-existing-ips) call.
</Message>

```bash
curl -X PATCH \
  -H "X-Auth-Token: $SCW_SECRET_KEY" \
  -H "Content-Type: application/json" \
  "https://api.scaleway.com/ipam/v1/regions/fr-par/ips/<ip-id>" \
  -d '{
    "reverses":[
        {
          "hostname":"reverse1.example.com",
          "address":"2001:db8::1"
        },
        {
          "hostname":"reverse2.example.com",
          "address":"2001:db8::2"
        },
        {
          "hostname":"reverse3.example.com",
          "address":"2001:db8::3"
        }
    ]
  }'
```
