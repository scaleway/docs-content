New asymmetric signature algorithms:

- ML-DSA-44
- ML-DSA-65
- ML-DSA-87

New Key Encapsulation Algorithms : 

- ML-KEM-768
- ML-KEM-1024

New Endpoints

- Wrap a key using ML-KEM. All details available in the [API documentation](https://www.scaleway.com/en/developers/api/key-manager/keys#wrap-a-key)
- Unwrap a key using ML-KEM. All details available in the [API documentation](https://www.scaleway.com/en/developers/api/key-manager/keys#unwrap-a-key)
