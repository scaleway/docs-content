Learn how to bind and detach [annotations](/annotations/concepts/glossary/#annotation) via the Scaleway console.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- One of the following [Annotations permission sets](/annotations/how-to/configure-annotations-permissions/):
  - `AnnotationsFullAccess`: Gives you full access to keys, values, and bindings
  - `AnnotationsBindingManager`: Allows you to create/delete bindings

## Bind an annotation to a resource

You can bind an annotation to a resource either while creating the resource or when the resource is already in place.

To bind an annotation to a resource that *already exists*:

1. Navigate to your resource in the [console](https://console.scaleway.com/), and click the **Settings** tab.

2. In the **Annotations** panel, use the dropdown to select the key, then the value. The key and value appear under the **Key** and **Value** fields. The annotation is now attached to your resource.

To bind an annotation to a resource *while creating it*, use the creation wizard.

1. When you get to the point in the wizard where you can enter a name and description for your resource, find the **Annotations** section.

2. Use the dropdown to select a key, then a value. The key and value appear under the **Key** and **Value** fields. The annotation is now attached to your resource.

## Detach an annotation from a resource

You can detach an annotation from a resource either via the Annotations page or directly from the page of the resource.

### Via the Annotations page

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your annotations appears.

2. Click the key whose value you want to edit. The overview page of the key opens. 

3. Click the name of the value that you want to edit. The overview page of the value opens. 

4. Click <Icon name="unlink" /> next to the resource that you wish to detach. In the dialog box that appears, click **Confirm**.

### Via the page of the resource

1. Navigate to your resource in the [console](https://console.scaleway.com/).

2. When you are on the overview page of the resource, click the **Settings** tab.

3. In the **Annotations** panel, click **X** next to the key and value that you want to detach. Both the selected key and value disappear under the **Key** and **Value** fields. The annotation is now detached from your resource.
