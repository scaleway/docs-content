The [Scaleway CLI](/scaleway-cli/quickstart/) lets you manage your Scaleway resources from a terminal. For Object Storage, the `scw object config` commands generate configuration files for Amazon S3-compatible tools ([rclone](https://rclone.org/), [s3cmd](https://github.com/s3tools/s3cmd), and [MinIO Client](https://github.com/minio/mc)) from your existing Scaleway CLI credentials.

The generated configuration files create a remote and an alias named `scaleway`, which the CLI examples of the Object Storage documentation use. To configure these tools manually, or to configure the AWS CLI, see [Configure CLI tools and clients for Object Storage](/object-storage/api-clients/cli-tools-and-clients/).

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A valid [API key](/iam/credentials/create-api-keys/)
- The [Scaleway CLI](/scaleway-cli/quickstart/) installed and initialized
- [rclone](https://rclone.org/downloads/), [s3cmd](https://github.com/s3tools/s3cmd), or [MinIO Client](https://github.com/minio/mc) installed

## Preview a configuration file

The `scw object config get` command displays the content of the configuration file in your terminal, so you can check its fields. Run `scw object config get --help` for more information.

The following tabs show the command and its output for each tool.

<Tabs>
  <TabsTab label="rclone">
    ```bash
    scw object config get type=rclone
    ```

    An output similar to the following appears:

    ```
    # Generated by scaleway-cli command
    # Configuration file for rclone https://rclone.org/s3/#scaleway
    # Default location: $HOME/.config/rclone/rclone.conf
    [scaleway]
    type = s3
    env_auth = false
    endpoint = s3.nl-ams.scw.cloud
    access_key_id = SCWEXAMPLED4PDEWS5M
    secret_access_key = example-d476-4bd5-b97d-2d97e04c3c4d
    region = nl-ams
    location_constraint =
    acl = private
    force_path_style = false
    server_side_encryption =
    storage_class =
    ```
  </TabsTab>
  <TabsTab label="s3cmd">
    ```bash
    scw object config get type=s3cmd
    ```

    An output similar to the following appears:

    ```
    # Generated by scaleway-cli command
    # Configuration file for s3cmd https://s3tools.org/s3cmd
    # Default location: $HOME/.s3cfg
    [default]
    access_key = SCWEXAMPLED4PDEWS5M
    bucket_location = nl-ams
    host_base = s3.nl-ams.scw.cloud
    host_bucket = %(bucket)s.s3.nl-ams.scw.cloud
    secret_key = example-d476-4bd5-b97d-2d97e04c3c4d
    use_https = True
    ```
  </TabsTab>
  <TabsTab label="MinIO Client">
    ```bash
    scw object config get type=mc
    ```

    An output similar to the following appears:

    ```
    {"version":"9","hosts":{"scaleway":{"url":"https://s3.nl-ams.scw.cloud","accessKey":"SCWEXAMPLED4PDEWS5M","secretKey":"example-d476-4bd5-b97d-2d97e04c3c4d","api":"S3v4"}}}
    ```
  </TabsTab>
</Tabs>

## Install a configuration file

The `scw object config install` command creates the configuration file of the selected tool, based on your [Scaleway CLI configuration](/scaleway-cli/quickstart/).

<Message type="important">
`scw object config install` overwrites the existing configuration file of the selected tool. To update an existing configuration, [preview the configuration file](#preview-a-configuration-file) and edit your file manually.
</Message>

The following tabs show the command and its output for each tool.

<Tabs>
  <TabsTab label="rclone">
    ```bash
    scw object config install type=rclone
    ```

    An output similar to the following appears:

    ```
    Configuration file successfully installed at /Users/yourusername/.config/rclone/rclone.conf.
    ```
  </TabsTab>
  <TabsTab label="s3cmd">
    ```bash
    scw object config install type=s3cmd
    ```

    An output similar to the following appears:

    ```
    Configuration file successfully installed at /Users/yourusername/.s3cfg.
    ```
  </TabsTab>
  <TabsTab label="MinIO Client">
    ```bash
    scw object config install type=mc
    ```

    An output similar to the following appears:

    ```
    Configuration file successfully installed at /Users/yourusername/.mc/config.json.
    ```
  </TabsTab>
</Tabs>

- [How to create a bucket](/object-storage/buckets/create-a-bucket/)
- [How to upload objects](/object-storage/objects/upload-objects/)
- [How to download objects](/object-storage/objects/download-objects/)
- [How to delete objects](/object-storage/objects/delete-objects/)

See the [rclone](https://rclone.org/docs/), [s3cmd](https://s3tools.org/s3cmd-howto), and [MinIO Client](https://github.com/minio/mc) documentation for more information on these tools.
