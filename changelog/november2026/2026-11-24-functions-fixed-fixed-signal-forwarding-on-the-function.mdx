---
title: Fixed signal forwarding on the Functions Python runtime
status: fixed
date: 2026-11-24
category: serverless
product: functions
---

Fixed an issue on the Serverless Functions on Python runtime where termination signals, such as `SIGTERM`, were not delivered to code when instances were stopped. 

These signals are now forwarded directly to the function, so you can implement graceful shutdown handling, for example to let in-flight requests complete.

To benefit from this fix, redeploy your functions.
