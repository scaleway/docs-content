Resizing an Instance, also called vertical scaling, changes its offer type to increase or decrease its CPU and RAM without recreating the Instance. Use it to scale up for increased traffic, scale down to reduce costs, or adapt an Instance to the requirements of your application.

You can also resize your Instance with the API or CLI. See [Changing the commercial type of an Instance with the API or CLI](/instances/api-cli/migrating-instances/) for more information. To increase the storage capacity of your Instance instead, see [How to increase the size of your Block Storage volumes](/block-storage/how-to/increase-block-volume/).

<Requirements />
- A Scaleway account logged in to the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Instance](/instances/how-to/create-an-instance/) using Block Storage volumes

## Change the offer type of an active Instance

You can change the offer type of an active Instance within the same Instance generation (for example, from BASIC3-X6C-12G to BASIC3-X6C-24G) or to a more recent generation (for example, from BASIC3 to POP2).

If your Instance uses [scratch storage](/instances/reference-content/understanding-scratch-storage/), copy any data you need to keep to a Block Storage volume or an Object Storage bucket before you change its offer type.

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to resize. The **Overview** page of the Instance opens.
4. Click **Change offer** in the **Instance information** section. The **Change offer type** page opens.
5. Select a new Instance configuration from the list of available offers. Recommended configurations are highlighted.
    - To stay within the same generation, select another offer from the same commercial range.
    - To move to a more recent generation, select an offer from a different commercial range further down the list.
6. Compare the monthly cost of the new configuration with your current offer.
7. Click **Change offer type**. The Instance reboots to apply the new offer type, which causes up to 5 minutes of downtime.

## Change the offer type of an end-of-life Instance

When an Instance reaches [end of life](/instances/reference-content/instance-lifecycle/#key-states), an alert banner appears on the **Overview** page of the Instance. The banner informs you that you must upgrade the Instance and recommends an equivalent offer.

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to upgrade. The **Overview** page of the Instance opens.
4. Click **Upgrade** in the **Instance information** section. The **Change offer type** page opens.
5. Select a new Instance configuration from the list of available offers. The recommended offer is preselected and appears at the top of the list.
6. Compare the monthly cost of the new configuration with your current offer.
7. Click **Change offer type**. The Instance reboots to apply the new offer type, which causes up to 5 minutes of downtime.
