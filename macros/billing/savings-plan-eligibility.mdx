macro: savings-plan-eligibility
---

The Compute savings plan applies simultaneously and in all regions to the following Instance ranges:

- Development
- General Purpose
- Production Optimized
- Workload Optimized
- Cost Optimized

The following Instance types are not eligible:

| Category | Instance types |
|---|---|
| Gen3 Instances | BASIC3-X, STANDARD3-X, COMPUTE3-X, MEMORY3-X |
| GPU Instances | B300, H100, L4, L40S, RENDER |
| Other Instances | COPARM, POP-WIN, START1, STARDUST, X64 |

<Message type="important">
  The list of eligible Instances is subject to periodic changes.
</Message>
