It is now possible to increase storage capacity by updating your cluster using `volume_size_bytes`. See the [Update a Kafka cluster](https://www.scaleway.com/en/developers/api/clusters-for-kafka/kafka-clusters#update-a-kafka-cluster) API documentation for more information.
