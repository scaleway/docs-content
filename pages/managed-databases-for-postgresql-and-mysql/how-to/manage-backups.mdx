Backups save the state of your Database Instance so you can restore or export it later. You can create backups manually or let autobackup create them on a schedule. This page explains how to create, schedule, restore, export, and delete backups.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A [PostgreSQL or MySQL Database Instance](/managed-databases-for-postgresql-and-mysql/quickstart/)

## Create manual backups

Manual backups let you save a specific state of your Database Instance. You can create manual backups for all Database Instances that use local volumes. For Database Instances that use Block Storage, you can create manual backups if the storage is 585 GB or less. Manual backups are subject to quota limitations.

1. Click the **Backups** tab of your Database Instance.
2. Click **Create backup**.
3. Enter a name for the backup, select the database, and set an expiration date. Scaleway deletes the backup automatically on that date.
4. Click **Create backup** to start the backup.
To change the name or expiration date of a backup later, click <Icon name="more" /> > **Edit** next to the backup.

## Configure automated backups

Autobackup automatically creates backups of your Database Instance on a schedule. For Database Instances that use local volumes, autobackups are [backups](/managed-databases-for-postgresql-and-mysql/concepts/#database-backup). For Database Instances that use [Block Storage](/managed-databases-for-postgresql-and-mysql/concepts/#block-storage), autobackups are snapshots. See [How to manage snapshots](/managed-databases-for-postgresql-and-mysql/how-to/manage-snapshots/#configure-automated-snapshots) for more information.

Autobackup is enabled by default when you create a Database Instance, with 1 backup per day kept for 7 days. To disable it before creation, select **Manual** in the **Choose a backup configuration** step of the creation wizard. Automated backups are not subject to quota limitations. See the [Managed Databases FAQ](/managed-databases-for-postgresql-and-mysql/faq/#why-is-my-number-of-active-backupssnapshots-exceeding-the-quota) for more information.

1. In the side menu, under **Databases**, click **PostgreSQL and MySQL**. The list of your Database Instances appears.
2. Select the region of your Database Instance from the dropdown.
3. Click the name of your Database Instance, or click <Icon name="more" /> > **More info**. The Database Instance's **Overview** page opens.
4. Click the **Settings** tab.
5. In the **Backup configuration** section, click **Edit**.
6. Select **Automated**.
7. Select the backup region, frequency, and retention period.
8. Click <Icon name="validate" /> to confirm.

<Message type="note">
  The base time for autobackups is when you created the Database Instance. When you change the schedule, it becomes the time you confirmed the change. For example, if you set the frequency to every day at 08:00 on a Thursday, the next backup happens at 08:00 on Friday.
</Message>

## Restore backups

You can restore a backup to its original database or to a new database.

1. Click the **Backups** tab of your Database Instance.
2. Click <Icon name="more" /> > **Restore** next to the backup you want to restore. A dialog box appears.
3. Select the Database Instance and the database to restore the backup to. If you restore to a new database, enter a name for it.
4. Click **Restore backup**. The restore process starts. Restoring a large backup can take several hours.

## Export backups

1. Click the **Backups** tab of your Database Instance.
2. Click <Icon name="more" /> next to the backup you want to export.
3. Click **Prepare export**. When the export is ready, the **Download** button appears.
4. Click **Download**.

PostgreSQL backups are exported in the PostgreSQL compression format. MySQL backups are exported as `.gzip` files.

## Delete backups

Deleting a Database Instance does not delete its backups, including backups created by autobackup. Scaleway deletes automated backups at the end of their retention period. You can also delete backups manually.

1. Click the **Backups** tab of your Database Instance.
2. Click <Icon name="more" /> > **Delete** next to the backup you want to delete. A dialog box appears.
3. Click **Delete backup** to confirm.
