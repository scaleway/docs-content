You can delete an Instance you no longer need from the Scaleway console. When you delete an Instance, you can choose to also delete its flexible IP addresses and Block Storage volumes.

Scaleway always deletes the [scratch volumes](/instances/reference-content/understanding-scratch-storage/) of an Instance with the Instance. You cannot keep scratch volumes.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Instance](/instances/how-to/create-an-instance/)

<Message type="important">
  Deleting an Instance is irreversible. All data stored on the Instance is permanently lost.
</Message>

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click <Icon name="more" /> next to the Instance you want to delete.
4. Click **Delete**. A dialog box appears asking you to confirm the action.
5. Type **DELETE** to confirm.
6. (Optional) If your Instance has flexible IP addresses or Block Storage volumes, check the corresponding boxes to delete them with the Instance.
7. Click **Delete Instance**. The Instance no longer appears in the list of your Instances.
