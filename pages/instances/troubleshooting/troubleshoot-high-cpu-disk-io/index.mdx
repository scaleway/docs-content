High CPU usage or disk I/O can make an Instance slow or unresponsive. A high load average does not always mean that the CPU is fully utilized. Processes waiting for disk I/O can also contribute to system load.

This page provides a practical Linux troubleshooting workflow using standard command-line tools.

## Before you start

To complete the steps below, you need:

- A running Scaleway Instance.
- SSH access to the Instance.
- `sudo` privileges.
