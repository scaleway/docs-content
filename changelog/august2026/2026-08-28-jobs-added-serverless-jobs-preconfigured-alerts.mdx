Serverless Jobs is now integrated with [preconfigured alerts for Cockpit](/cockpit/how-to/activate-managed-alerts/#how-to-activate-preconfigured-alerts), offering 3 new alerts:
* Job run failed
* High CPU usage
* High memory usage
