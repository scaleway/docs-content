Scaleway Elastic Metal servers are on-demand, dedicated physical servers. These servers are ideal for large workloads, big data, and applications that require increased security and dedicated resources. You can install an Operating System (OS) or other [image](/elastic-metal/concepts/#image) on your Elastic Metal server and connect to it via SSH. You can power off the server when you are not using it, or delete it from your account when you no longer need it.

## Create an Elastic Metal server

1. In the **Bare Metal** section of the [Scaleway console](https://console.scaleway.com) side menu, click **Elastic Metal**. The Elastic Metal server dashboard opens.
2. Click **Create Elastic Metal server** to start the server creation wizard.
3. Complete the server creation wizard:
    - Choose an Availability Zone to determine the geographical location of your server. For a complete list of supported locations, see [Product availability by region](https://www.scaleway.com/en/product-availability-by-region/?categories=bare-metal). 
    - Choose a billing method: **hourly** or **monthly**. You can [change the billing method](/elastic-metal/how-to/change-billing-period/) at any time after your server has been delivered.
    - Select a server configuration from the available options.
    - Choose a pre-configured OS image to install, or choose **No Image** to decide later.
    - Configure disk partitioning. Choose the default configuration or [configure your own partitioning](/elastic-metal/how-to/configure-disk-partitions/) using a JSON configuration.
    - Enter a name and optional tags for your server.
    - Add your [SSH key](/iam/security/create-ssh-key/) (required to install an image on your server). Depending on the OS image, you also need to configure the panel user for your server.
    - Optional: configure the available public bandwidth (only for compatible offers).
    - Optional: enable the [Private Networks](/vpc/concepts/#private-networks) feature.
    - Review the estimated environmental footprint of your Elastic Metal server. For a detailed report on how this environmental footprint is calculated, refer to the [Environmental Footprint calculator breakdown](/environmental-footprint/additional-content/environmental-footprint-calculator) page.
    - Review the estimated cost based on your configuration.

4. Click **Create Elastic Metal server** to finalize your order.

You can monitor the delivery progress from the list of Elastic Metal servers in the console.

## Install an Elastic Metal server

<Message type="note">
  Follow this procedure if you created your server without a preinstalled Operating System (OS). Make sure your server status is `Ready` before proceeding.
</Message>

1. In the **Bare Metal** section of the [Scaleway console](https://console.scaleway.com) side menu, click **Elastic Metal**. The Elastic Metal server dashboard opens.
2. Choose the Elastic Metal server you want to install from the list.
3. Click **Install** to launch the OS installation wizard.
4. Choose the OS that you want to install.
5. Add your [SSH key](/organizations-and-projects/concepts/glossary/#ssh-key). If you previously [uploaded an SSH key](/iam/security/create-ssh-key/#how-to-upload-the-public-ssh-key-to-the-scaleway-interface), it appears in the list of keys.
6. Check the corresponding boxes to grant access to the server.
7. Click **Install server**.

## Power off an Elastic Metal server

You can power off an Elastic Metal server directly from the Scaleway console.

<Message type="important">
  Make sure to stop your operating system by executing the `halt` command before powering off the server. Otherwise, you risk damaging the file system and causing data loss.
</Message>

1. In the **Bare Metal** section of the [Scaleway console](https://console.scaleway.com) side menu, click **Elastic Metal**. The Elastic Metal server dashboard opens.
2. Click <Icon name="more" /> next to the server you want to power off.
3. Click **Power off** in the dropdown menu.
4. Confirm that you have shut down the operating system and click **Power off Elastic Metal server**.
