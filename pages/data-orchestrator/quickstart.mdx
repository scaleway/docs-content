Data Orchestrator is designed to help the user automate, schedule, and manage data workflows across various systems and environments.
Follow this guide to create your first workflow and take it through its full lifecycle.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A [Container Registry namespace](/container-registry/how-to/create-namespace/)
- An image [pushed](/container-registry/how-to/push-images/) to your namespace (for task execution)
- Created at least 2 [Serverless Jobs](/serverless-jobs/how-to/create-job/)
- Basic familiarity with YAML syntax
- Basic familiarity with the [Open Workflow Specification](https://open-workflow-specification.org/)

## Create a workflow

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Data & Analytics** > **Data Orchestrator**. The list of your workflows appears.
2. Click **Create workflow**. The Data Orchestrator workflow creation wizard opens.
3. Select the region for your workflow.
4. Enter a name or use the automatically generated one.
5. Click **Create workflow and add tasks**.
6. Click **Choose a job** to create the first task. The graph view opens with an empty job task created.
7. Click the empty job task to select the wanted Serverless Job.
    1. Select the region of the job.
    2. Select a job. 
8. In the tasks menu on the left, click **Serverless Jobs** to create a new empty job task. The new task appears to the right of the last created task. Click it and select the second job.
9. Click and hold the connector at the right of your first task then drag and drop it on the connector at the left of the second task to create a connection.
10. Click **Save changes** to finish, or click **Save and run** if you want to save and run the workflow.

## Monitor a running workflow

1. Click the name of the workflow you want to monitor. The workflow **Overview** tab opens.
2. Make sure the last run status is `Running` or `Queued`.
3. Click **View run** next to the last run status. The run information appears.

## Schedule a workflow

1. Click the name of the workflow you want to manage. The workflow **Overview** tab opens.
2. Click the **Settings** tab.
3. Check the **Enable run scheduling** box.
4. Enter the cron expression and the time zone.
5. Click **Save changes**.

## Delete a workflow 

1. Click the name of the workflow you want to delete. The workflow **Overview** tab opens.
2. Navigate to the **Settings** tab.
3. Click **Delete Workflow**.
4. Type **DELETE** to confirm.
5. Click **Delete Workflow**.
