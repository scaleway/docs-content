<Message type="important">
**Ingress NGINX reached end-of-life in March 2026** and no longer receives releases, bug fixes, or security patches.
While existing installations remain functional, Scaleway strongly recommends migrating to an actively maintained solution:
- Gateway API – Supported on Kapsule (manual installation required). Note that the Cilium Gateway API implementation is not supported.
- An alternative Ingress controller – Choose a third-party controller maintained by the Kubernetes community.
See the [official retirement announcement](https://kubernetes.io/blog/2025/11/11/ingress-nginx-retirement/) for full details.
</Message>
