## Problem

You experience one or more of the following issues when using an application on a file system:

- Conflicting locks on files
- The application does not start properly
- `ENOSYS`errors appear

## Cause

Scaleway File Storage only supports advisory locking, and does not support the `flock` syscall. Read and write operations do not check for conflicting locks before executing.

Applications that rely on `flock` to manage concurrent access to files cannot work properly on File Storage.

## Possible solution

Use File Storage for use cases that do not have strict `flock` requirements, such as:

- Content Management Systems (CMS) with no strict file locking requirements
- AI and machine learning workloads, to share model weights and datasets across a cluster of GPU or CPU Instances
