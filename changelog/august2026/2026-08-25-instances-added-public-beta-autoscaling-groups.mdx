Instance Autoscaling Groups is now available in Public Beta for the fr-par, nl-ams, and pl-waw regions.

This new feature enables automatic scaling and health management for standard Instance workloads based on resource consumption metrics, eliminating the need to containerize applications or manage complex orchestrators.

For more information, see:

- [Scaleway Autoscaling Groups documentation](/instances/how-to/create-manage-instance-groups/)
- [Scaleway Autoscaling API reference](https://www.scaleway.com/en/developers/api/autoscaling)
