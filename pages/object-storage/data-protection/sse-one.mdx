<SseOneIntroduction />

You can enable and disable SSE-ONE from the [Scaleway console](https://console.scaleway.com) or with the AWS CLI. Each procedure on this page describes both methods.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Object Storage bucket](/object-storage/buckets/create-a-bucket/), unless you enable SSE-ONE during bucket creation
- The [AWS CLI](/object-storage/api-clients/cli-tools-and-clients/) installed and configured, if you use the CLI

## Enable SSE-ONE during bucket creation

When you [create a bucket](/object-storage/buckets/create-a-bucket/) in the console, check the **Enable bucket encryption** box and select the **SSE-ONE** encryption type. Object Storage automatically encrypts the objects you upload to the bucket at rest, with keys managed by Scaleway.

## Enable SSE-ONE on an existing bucket

<Message type="important">
Encryption happens when you upload an object. Objects uploaded to the bucket before you enable SSE-ONE remain unencrypted.
</Message>

The following tabs describe how to enable SSE-ONE on an existing bucket using the console or the AWS CLI.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of the bucket. The **Overview** tab of the bucket appears.

    3. Click the **Settings** tab.

    4. Under **Bucket encryption**, click **Edit encryption mode**. A dialog box appears.

    5. Check the **Enable bucket encryption** box, then select **SSE-ONE**.

    6. Click **Confirm**.
  </TabsTab>
  <TabsTab label="AWS CLI">
    1. Run the following command to enable SSE-ONE on your bucket. Replace `<BUCKET_NAME>` with the name of your bucket.
        ```bash
        aws s3api put-bucket-encryption \
          --bucket <BUCKET_NAME> \
          --server-side-encryption-configuration '{
            "Rules": [
              {
                "ApplyServerSideEncryptionByDefault": {
                  "SSEAlgorithm": "AES256"
                }
              }
            ]
          }'
        ```

    2. Run the following command to check the encryption configuration of the bucket:
        ```bash
        aws s3api get-bucket-encryption --bucket <BUCKET_NAME>
        ```
        An output similar to the following appears:
        ```json
        {
          "ServerSideEncryptionConfiguration": {
            "Rules": [
              {
                "ApplyServerSideEncryptionByDefault": {
                  "SSEAlgorithm": "AES256"
                },
                "BucketKeyEnabled": false
              }
            ]
          }
        }
        ```
  </TabsTab>
</Tabs>

Object Storage automatically encrypts each object you upload to the bucket from now on, using AES-256 keys managed by Scaleway.

## Disable SSE-ONE on a bucket

After you disable SSE-ONE, Object Storage no longer encrypts new objects. Objects uploaded while SSE-ONE was enabled remain encrypted.

The following tabs describe how to disable SSE-ONE using the console or the AWS CLI.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of the bucket. The **Overview** tab of the bucket appears.

    3. Click the **Settings** tab.

    4. Under **Bucket encryption**, click **Edit encryption mode**. A dialog box appears.

    5. Uncheck the **Enable bucket encryption** box.

    6. Click **Confirm**. The **Disable encryption for my bucket** dialog box appears.

    7. Type **DISABLE**, then click **Confirm**.
  </TabsTab>
  <TabsTab label="AWS CLI">
    1. Run the following command to disable SSE-ONE on your bucket:
        ```bash
        aws s3api delete-bucket-encryption --bucket <BUCKET_NAME>
        ```

    2. Run the following command to check the encryption configuration of the bucket:
        ```bash
        aws s3api get-bucket-encryption --bucket <BUCKET_NAME>
        ```
        An output similar to the following appears:
        ```json
        {
          "ServerSideEncryptionConfiguration": {}
        }
        ```
  </TabsTab>
</Tabs>

You can [enable SSE-ONE](#enable-sse-one-on-an-existing-bucket) again at any time.
