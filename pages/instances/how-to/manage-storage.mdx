You can manage the storage resources of your Instances from the **Storage** tab of each Instance in the Scaleway console:

- [Volumes](#manage-volumes) store the data of your Instance. You can attach several volumes to an Instance.
- [Snapshots](#manage-snapshots) capture the state of a volume at a specific time, including the OS, configuration, and stored files.
- [Images](#manage-images) are full backups of an Instance. Use them to restore data or to deploy several Instances with the same configuration.

<Requirements />
- A Scaleway account logged in to the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Instance](/instances/how-to/create-an-instance/)

## Manage volumes

Volumes are the primary storage of your Instances. Depending on its offer type, an Instance supports the following volume types:

- **Block Storage**: Network-based storage with 5,000 or 15,000 IOPS. Block Storage volumes are persistent.
- **Local Storage**: Storage located on the physical hypervisor and tied to the compute resources of the Instance.
- **Scratch storage**: Fast, temporary local Non-Volatile Memory Express (NVMe) storage, available on Standard3-x, Compute3-x, and Memory3-x Instances. Powering off or resizing the Instance erases all data stored on scratch volumes. See [How to use scratch storage](/instances/how-to/use-scratch-storage/) for more information.

If a volume does not appear in the **Storage** tab of your Instance, check the [Block Storage](https://console.scaleway.com/block-storage/volumes) or [Local Storage](https://console.scaleway.com/local-storage/volumes) pages of the console.

### View and manage volumes

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to manage. The **Overview** page of the Instance opens.
4. Click the **Storage** tab. The **Volumes** section lists the volumes attached to the Instance.
5. Click <Icon name="more" /> next to a volume to display the available actions:
    - View the volume details
    - [Increase the volume size](/block-storage/how-to/increase-block-volume/)
    - [Detach the volume](/block-storage/how-to/detach-a-volume/)
    - [Create a snapshot](/block-storage/how-to/create-a-snapshot/)
    - [Delete the volume](/block-storage/how-to/delete-a-volume/)

### Add a volume

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to add a volume to. The **Overview** page of the Instance opens.
4. Click the **Storage** tab.
5. Click **Add volume** in the **Volumes** section. The **Add volume** dialog box appears.
6. Enter a name for the volume, or keep the randomly generated name.
7. Enter the size of the volume in GB.
8. Select a volume type. The monthly price of the volume appears next to each volume type.
9. Click **Add volume**. The volume appears in the **Volumes** section.

## Manage snapshots

Snapshots capture the state of a volume at a specific time. Use them to recover data or to create new volumes and images.

### View and manage snapshots

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to manage. The **Overview** page of the Instance opens.
4. Click the **Storage** tab.
5. Scroll down to the **Snapshots** section.
6. Click <Icon name="more" /> next to a snapshot to display the available actions:
    - View the snapshot details
    - [Create an image from the snapshot](/instances/how-to/create-image-from-snapshot/)
    - [Create a volume from the snapshot](/block-storage/how-to/create-volume-from-snapshot/)
    - Copy the snapshot to an Object Storage bucket
    - [Delete the snapshot](/block-storage/how-to/delete-a-snapshot/)

### Create a snapshot

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to manage. The **Overview** page of the Instance opens.
4. Click the **Storage** tab.
5. Click **+ Create snapshot** in the **Snapshots** section. A dialog box appears.
6. Select the volume to snapshot from the dropdown.
7. Enter a name for the snapshot.
8. Click **Create snapshot**. The snapshot appears in the **Snapshots** section.

You cannot create snapshots of [scratch volumes](/instances/reference-content/understanding-scratch-storage/).

## Manage images

Images are full backups of Instances. Use them to restore data or to deploy several Instances with the same configuration.

### View and manage images

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to manage. The **Overview** page of the Instance opens.
4. Click the **Storage** tab.
5. Scroll down to the **Images** section.
6. Click <Icon name="more" /> next to an image to display the available actions:
    - View the image details
    - Create an Instance from the image
    - Delete the image

### Create an image

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to manage. The **Overview** page of the Instance opens.
4. Click the **Storage** tab.
5. Click **+ Create image** in the **Images** section. A dialog box appears.
6. Enter a name for the image.
7. Click **Create image**. The image appears in the **Images** section.
Images do not include [scratch volumes](/instances/reference-content/understanding-scratch-storage/).
