Powering off your Instance shuts it down and transfers all the data on its local volumes to a volume store. Scaleway then releases the hypervisor back to the pool of available machines. Flexible IP addresses stay in your account, and attached Block Storage volumes remain intact.

Before you power off your Instance, shut down its OS from inside the Instance, for example with the `shutdown` command. Powering off can take some time, depending on the amount of data stored on the local volumes of the Instance.

Scratch volumes are not transferred to a volume store. To stop an Instance that uses [scratch storage](/instances/reference-content/understanding-scratch-storage/) without losing its scratch data, use [standby mode](/instances/how-to/use-standby-mode/) instead.

## Power off an Instance

<Message type="important">
  When an Instance is powered off, Scaleway continues to bill its volumes and any reserved flexible IP address.
</Message>

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to power off. The **Overview** page of the Instance opens.
4. Click the <Icon name="toggle" /> toggle in the top right corner of the page. A dialog box appears asking you to confirm the action.
5. Click **Power off Instance**. The Instance shuts down and its status changes to **Stopped**.

## Power on an Instance

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to power on. The **Overview** page of the Instance opens.
4. Click the <Icon name="toggle" /> toggle in the top right corner of the page. A dialog box appears asking you to confirm the action.
5. Click **Power on Instance**. The Instance starts and its status changes to **Running**.

If your Instance uses scratch storage, its scratch volumes are empty and unformatted when the Instance starts. See the [Use scratch storage](/instances/how-to/use-scratch-storage/#create-a-file-system-on-a-scratch-volume) documentation for more information.
