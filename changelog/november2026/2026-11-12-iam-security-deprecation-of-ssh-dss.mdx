---
title: Deprecation of ssh-dss
status: security
date: 2026-11-12
category: security-identity
product: iam
---

SSH Keys with DSA keys (ssh-dss) are no longer supported. It is not possible to add new SSH keys with the DSA algorithm. We strongly recommend replacing them with ed25519 or RSA keys. See [How to generate and SSH key pair](https://www.scaleway.com/en/docs/iam/security/create-ssh-key/) for instructions on generating a new one.
