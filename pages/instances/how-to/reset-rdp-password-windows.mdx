The **Administrator** password of a Windows Instance is generated and encrypted with the ssh public key. If you need to reset this password, you can generate a new one by clearing the SSH key associated with the Instance and then restore it to its previous value. After a reboot of the instance, the Administrator password will be reset.

<Message type="important">
  Resetting the password is an **irreversible action**. Any new RDP session will need to use the new password.
</Message>

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A [Windows Instance](/instances/how-to/create-an-instance/)
- An [SSH key](/iam/security/create-ssh-key/) (RSA) used to encrypt the Administrator password
- The [Scaleway CLI](https://github.com/scaleway/scaleway-cli) installed and configured on your local machine

1. Identify the ID of your Instance and its Availability Zone (AZ). You can view them in the [console](https://console.scaleway.com/instance/servers) or run the following command:
    ```bash
    scw instance server list
    ```
2. List the SSH keys of your Project to identify the SSH key you want to use to encrypt the new Administrator password:
    ```bash
    scw iam ssh-key list
    ```
    Note down the ID of this SSH key (e.g. the same key that was used when creating the Instance). You will use it in step 4 to restore the `admin-password-encryption-ssh-key-id` field.
3. Clear the SSH key by setting the `admin-password-encryption-ssh-key-id` field to an empty string:
    ```bash
    scw instance server update <YOUR_INSTANCE_ID> zone=<YOUR_AVAILABILITY_ZONE> admin-password-encryption-ssh-key-id=""
    ```
    <Message type="note">
      Setting this field to an empty string resets both the SSH key and the encrypted password (`admin_password_encrypted_value`), so that a new password can be generated.
    </Message>
4. Restore the SSH key to its previous value:
    ```bash
    scw instance server update <YOUR_INSTANCE_ID> zone=<YOUR_AVAILABILITY_ZONE> admin-password-encryption-ssh-key-id=<YOUR_SSH_KEY_ID>
    ```
5. Reboot the Instance from the Scaleway CLI to trigger the generation of the new password:
    ```bash
    scw instance server reboot <YOUR_INSTANCE_ID> zone=<YOUR_AVAILABILITY_ZONE>
    ```
    <Message type="important">
      The reboot **must** be performed via the Scaleway CLI (or the Scaleway console). A software reboot issued from within the Instance (e.g. the `shutdown /r` command) is **not sufficient** and will not generate a new password.
    </Message>
6. Retrieve the newly generated password with the Scaleway CLI, replacing `<YOUR_PRIVATE_RSA_SSH_KEY_FILE>` with the path to your private RSA SSH key:
    ```bash
    scw instance server get-rdp-password <YOUR_INSTANCE_ID> zone=<YOUR_AVAILABILITY_ZONE> key=<YOUR_PRIVATE_RSA_SSH_KEY_FILE>
    ```
    The new Administrator password displays:
    ```plaintext
    Username           Administrator
    Password           nlW_=v->I"mWuEz
    SSHKeyID           73f6f13e-0f34-45d0-a61c-463e0289b4a4
    SSHKeyDescription  My RSA SSH key
    ```
    <Message type="tip">
      The password is generated and encrypted with the public part of the SSH key you restored. If it is not yet available, add the `-w` (wait) flag to the command above to wait for its generation.
    </Message>
7. Launch your Remote Desktop client and connect to your Instance using its IP address, the username **Administrator**, and the new password. For more information, refer to the section about [connecting to Windows Instances](/instances/how-to/connect-to-instance/).
    <Message type="tip">
      - The password is only displayed once. Save it in a safe place.
      - This procedure only works with an RSA SSH key.
    </Message>
