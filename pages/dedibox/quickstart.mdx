[Scaleway Dedibox](https://www.scaleway.com/en/dedibox/) are high-quality dedicated servers. With over 15 years of experience, Scaleway provides dedicated servers that are recognized for their extreme reliability and best-in-class redundancy.

<Requirements />

- A Dedibox account logged in to the [console](https://console.online.net)
- [Added a payment method](/dedibox-account/how-to/add-payment-method/) to your account

## How to order a server

1. In your [Dedibox console](https://console.online.net) homepage, click **Order** > **Dedicated server**. The server offers page opens. 
    You can view all servers available in your preferred data center by clicking the **Datacenter selection** drop-down menu in the top right corner.
2. Select a server model and click the **Order** button next to your choice. The server creation wizard opens.
3. Complete the following steps in the wizard:
    - Select your commitment period: rent without commitment, or choose a 12-24-36 month plan for lower monthly rates and free server setup.
      <Message type="note">
        This step only appears for Dedibox servers eligible to a commitment plan.
      </Message>
    - Select the data center. Some server models are available in more than one data center. If you have no preference, select **"No preference"**.
    - Choose the service level. There are two plans available:
      - **Basic service level** - Free plan included with any Dedibox server:
        - Ticket support
        - Phone support
        - Sales support
        - SLA (See the [Service Level Agreement for Bare Metal Services](https://www.scaleway.com/en/bare-metal/sla/) for more details)
        - RPN (Real Private Network) with limited bandwidth
      - **Business service level** - Paid plan adapted to the professional use of a Dedibox server:
        - Ticket support
        - Phone support
        - Sales support
        - Priority technical support
        - SLA (See the [Service Level Agreement for Bare Metal Services](https://www.scaleway.com/en/bare-metal/sla/) for more details)
        - RPN (Real Private Network) with high bandwidth
        - Customization (disks, bandwidth)
        - Security options (DDoS)
    - Configure the available options:
        <Message type="note">
          The list may vary according to your Dedibox server and your service level plan.
        </Message> 
      - Select a backup option: 750 GB FTP, 100 GB FTP, or **no FTP backup**
      - Choose a plan for protection against DDoS
      - Select an extra network-attached storage, or **No SAN**
      - Select the public bandwidth
4. Click **Order**. A summary of your order appears.
5. Select your payment method in the **Payment mode choice** drop-down menu in the top right corner.
6. Check the boxes confirming that you have read and agreed to the terms of service.
7. Click **Confirm my order**. A confirmation of your order appears.


## How to install a server

Once your server is ready, you can start the installation.

1. In your [Dedibox console](https://console.online.net) top menu, click **Server** > **Server list**. The list of your servers opens.
2. Click **Manage** next to the server you want to install. The server installation wizard opens.
3. Select the type of operating system you want to install. 

    For more information about OS types, refer to the [dedicated servers concepts page](/dedibox/concepts/#os-type).
    
    If you want to complete your installation using [KVM Over IP](dedibox-kvm-over-ip/), click **Install over KVM** instead.
4. Choose the operating system and version, and click **Install**.
5. Customize the following [partitioning](/dedibox/concepts/#partitioning) parameters:
   - Select the **File system**, **RAID level**, and specify the **mount point** and **partition size** in MB.
   - If the server has two disks, you can choose between **RAID 0**, **RAID 1**, or **No RAID**. For servers with more than two disks, **RAID 5** is also available. Configure the RAID and partitioning according to your needs. Ensure identical partitioning across all disks in a software RAID setup.

   **Partitioning restrictions:**
   - A maximum of 4 primary partitions per disk is allowed.
   - Do not create a `/var` partition, as it may cause installation failure.
   - The `/` partition must be at least 2048 MB.
6. Click **Validate**.
7. Configure the system parameters. You can edit parameters such as the name of the server, add a username, a password, an SSH key, and configure monitoring alerts and updates.
    <Message type="note">
      To connect to your server via SSH, it is recommended that you [create and upload your SSH key](/dedibox-account/how-to/upload-an-ssh-key/) at this stage so that it can be transferred to your server during installation.
    </Message>
8. Check that all information you entered is correct on the installation summary tab.

    Once the installation completes, your server will reboot on its hard disk.

Depending on the OS, the installation may take several minutes to complete. Certain operating systems may require additional reboots for completion. Scaleway recommends waiting 45 to 60 minutes before you connect to your server.

## How to connect to your server

A common way of connecting to your Dedibox server is via the command line, using SSH. SSH is a secure communication protocol, which imposes an encryption key exchange at the beginning of the connection. This means that the exchange of data between the client and the server will be encrypted.

However, you may also connect to your server via a graphical interface, such as Windows Remote Desktop.

You can also use FTP, SFTP, or SCP to transfer data to and from your server.

<Requirements />

- A Dedibox account logged in to the [console](https://console.online.net)
- [Created and uploaded your SSH key](/dedibox-account/how-to/upload-an-ssh-key/)
- [Created](/dedibox/how-to/order-a-server/) and [installed](/dedibox/how-to/install-a-server/) a dedicated server and transferred your SSH key to the server during installation

## How to connect via SSH

### From OSX (Mac) and Linux

1. Open a terminal window on your local machine.
2. Enter the command below into the terminal. Make sure you replace `<YOUR_PRIVATE_KEY>` with the filename of your [private key](/dedibox-account/how-to/upload-an-ssh-key/) (often `id_rsa`) and `<YOUR_SERVER_IP>` with the IP address of your server.
    ```bash
    ssh -i ~/.ssh/<YOUR_PRIVATE_KEY> root@<YOUR_SERVER_IP>
    ```
3. If prompted, allow connection to the host by typing `yes`, then press **Enter**.
    ```
    The authenticity of host 'myhost.ext (212.47.226.35)' cannot be established.
    RSA key fingerprint is 4f:ba:65:cf:14:64:a7:1e:b6:07:7c:00:71:95:21:fa.
    Are you sure you want to continue connecting (yes/no)?
    ```

You are now connected to the server.

### From Windows

To connect to your server from Windows, you will need to use a small application called **PuTTY**, an SSH client.

1. Download and install [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html).
2. Launch PuTTY on your computer. The main screen of the application opens.
3. In the **Hostname** field, enter your Server IP address.
    <Message type="tip">
      You can find your server IP address in the **Server tab** of the [Dedibox console](https://console.online.net/en/server/list).
    </Message>
4. In the side menu, go to **Connection** > **SSH** > **Auth**.
5. Click **Browse** and select your [private key](/dedibox-account/how-to/upload-an-ssh-key/) file.
6. Click **Open** to start the connection. When prompted, confirm the connection to the host. The terminal window opens.
7. Enter your **username** and **password** to authenticate using your SSH key.

You are now connected to your server.

## How to connect via Remote Desktop

If you have installed Windows Server on your Dedibox, follow these steps to connect to your Dedibox server from your local Windows machine using Remote Desktop.

1. Open **Remote Desktop Connection** on your local Windows PC.
2. Click **Show Options** (bottom-left) to reveal all connection fields.
3. Enter your connection details:
   - **Computer:** Enter your Dedibox server IP address (e.g., `163.172.20.1`).
   - **User name:** Enter `Administrateur` (default for Dedibox Windows Server).
4. Click **Connect**.
5. When prompted, enter the password configured during server installation and click **OK**.
6. Accept the certificate if asked by clicking **Yes**.

You are connected to the graphical interface of your Windows Server. If you need to change the language, see the [How to change the language of Windows Server](/dedibox/how-to/change-win-server-language/) page.
