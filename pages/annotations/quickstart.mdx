Follow this quickstart to learn the basics of [Annotations](/annotations/concepts/glossary/#annotations).

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- The `AnnotationsFullAccess` permission set, which gives you full access to keys, values, and bindings. See [configure an Annotation permission set in IAM](/annotations/setup-lifecycle/configure-annotations-permissions/) to learn how to set up `AnnotationsFullAccess`.

## Create an annotation

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The **Annotations** product page opens.
2. Click **Create annotation**. The creation wizard opens.
3. Enter a unique name for your key, and optionally a description.
4. Enter a value, and optionally a description for it.
5. Click **Create annotation**.

## Bind an annotation to a resource

You can bind an annotation to a resource either from the **Overview** page of the resource in the console or using the [Annotations API](https://www.scaleway.com/en/developers/api/annotations).

### Using the console

To bind an annotation to a resource on the **Overview** page of the resource:

1. In the [console](https://console.scaleway.com/) side menu, navigate to your chosen resource (e.g., a bucket) and select the **Overview** tab.

2. In the **Annotations** section, use the dropdown to select the key, then the value. 

3. Click the **Check mark** icon.

        The key-value pair is now attached to your resource.

### Using the Annotations API

To bind an annotation to a resource using the [Annotations API](https://www.scaleway.com/en/developers/api/annotations):

1. Export your API secret key and Organization ID. Remember to replace the placeholders with your actual values.

    ```bash
    export SCW_SECRET_KEY="<YOUR_SCW_SECRET_KEY>"
    export SCW_ORGANIZATION_ID="<YOUR_ORGANIZATION_ID>"
    ```

2. Retrieve the Scaleway Resource Name (SRN) of your resource. For example, let's suppose that you want to obtain the SRN of a Kubernetes cluster:

    ```bash
    curl -X GET \
    -H "X-Auth-Token: $SCW_SECRET_KEY" \
    "https://api.scaleway.com/k8s/v1/regions/{REGION}/clusters"   
    ```

    The response returns an array of your Kubernetes clusters in the given region. Copy and save the `"srn"` of the cluster that you want to bind the annotation to.

2. Retrieve the identifier of the value that you want to attach to your resource: 

    ```bash
    curl -X GET \
    -H "X-Auth-Token: $SCW_SECRET_KEY" \
    "https://api.scaleway.com/annotations/v1/values?organization_id=$SCW_ORGANIZATION_ID"
    ```
    The response returns an array of values. Copy and save the `"id"` of the value that you want to attach to your resource.

3. Bind the key-value pair to your selected cloud resource. Remember to replace the placeholders with the actual values that you retrieved in the previous steps:

    ```bash
    curl -X POST \
    -H "X-Auth-Token: $SCW_SECRET_KEY" \
    -H "Content-Type: application/json" \
    -d '{"target_srn":"<SRN>","value_id":"<ID_OF_VALUE>"}' \
    "https://api.scaleway.com/annotations/v1/bindings"
    ```

    The API returns a response like this:

    ```bash
    {
        "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "srn": "srn://annotations.scw.eu/bindings/a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "target_srn": "srn://k8s.scw.eu/regions/fr-par/clusters/fedcba98-7654-3210-fedc-ba9876543210",
        "key": {
            "id": "12345678-90ab-cdef-1234-567890abcdef",
            "srn": "srn://annotations.scw.eu/keys/12345678-90ab-cdef-1234-567890abcdef",
            "name": "my-key"
        },
         "value": {
            "id": "abcdef12-3456-7890-abcd-ef1234567890",
            "srn": "srn://annotations.scw.eu/values/abcdef12-3456-7890-abcd-ef1234567890",
            "name": "my-value"
        }
    }
    ```

## Manage a key 

### Edit a key

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your keys appears.

2. Click the <Icon name="more" /> **More** icon next to the key you want to edit. Click **Edit key** in the menu. The **Edit key** dialog box appears.

3. Change the key name and/or description, then click **Update**.

### Delete a key

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your keys appears.

2. Click the <Icon name="more" /> **More** icon next to the key you want to delete. Click **Delete key** in the menu.
    
    A confirmation dialog box appears.

3. *If the key has no associated value*, click **Confirm**.

4. *If the key has one or more associated values and maybe even resources*, deleting the key will break those associations. You must [remove bindings](#detach-a-resource-from-a-value) and [delete values](#delete-a-value) first. After removing the bindings and values, you can delete the key.

## Manage a value

### Edit a value

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your keys appears.

2. Click the key whose value you want to edit. The overview page of the key opens. 

3. Click the <Icon name="more" /> **More** icon next to the value you want to edit. Click **Edit value** in the menu. The **Edit value** dialog box appears.

4. Change the value name and/or description, then click **Update**.

### Delete a value

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your keys appears.

2. Click the key whose value you want to delete. The overview page of the key opens. 

3. Click the <Icon name="more" /> **More** icon next to the value you want to delete. Click **Delete value** in the menu. A confirmation dialog box appears.

4. *If the value is not bound to any resource*, click **Delete**. 

5. *If the value is bound to one or more resources*, you must [remove the binding](#detach-an-annotation-from-a-resource) first.

## Detach an annotation from a resource

You can detach an annotation from a resource either via the Annotations page or directly from the **Overview** page of the resource.

### Using the Annotations page

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your keys appears.

2. Click the key whose value you want to detach from the resource. The overview page of the key opens. 

3. Click the name of the value that you want to detach. The overview page of the value opens.  

4. Click the <Icon name="unlink" /> **Detach resource** icon next to the resource that you wish to detach. In the dialog box that appears, click **Confirm**.

### Using the Overview page of the resource

1. In the [console](https://console.scaleway.com/) side menu, navigate to your chosen resource (e.g., a bucket) and select the **Overview** tab.

2. In the **Annotations** section, click the **X** icon next to the key-value pair that you want to detach.

        The binding is now removed between your resource and the key-value pair.
