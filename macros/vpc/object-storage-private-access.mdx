<Message type="important">
Object Storage private access is currently in private beta, and is available in the Paris (`fr-par`) region only.
</Message>

Object Storage private access allows resources in your Private Networks to reach Object Storage over the internal Scaleway network, instead of the public internet.

Buckets are always served on 2 endpoints, whether the feature is enabled or not:

| Endpoint     | Regional URL                 | Bucket URL                                  |
|--------------|------------------------------|---------------------------------------------|
| Public       | `s3.<region>.scw.cloud`      | `<bucket_name>.s3.<region>.scw.cloud`       |
| Private      | `s3-vpc.<region>.scw.eu`     | `<bucket_name>.s3-vpc.<region>.scw.eu`      |

Enabling Object Storage private access on a VPC makes the private endpoint reachable from the Private Networks you authorize, for all buckets in the region of the VPC. Without it, the private endpoint is not reachable from a Private Network.

The feature adds a private path to your buckets. It does not remove the public path, and it does not change the permissions of your buckets.
