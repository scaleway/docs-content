title: Scaleway-managed IAM groups - All Users and All Applications
status: added
date: 2026-09-02

product: iam

Two new Scaleway-managed IAM groups have been added in all Organizations: 

**The All Users group** dynamically contains all the Users in your Organization
**The All Applications group** dynamically contains all the Applications in your Organization, except the Scaleway-managed applications.

You can use these two groups to manage permissions at scale without the need to manually manage group members.
