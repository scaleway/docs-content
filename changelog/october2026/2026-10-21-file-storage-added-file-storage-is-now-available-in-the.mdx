[File Storage](/file-storage/) is now in General Availability in the AMS region.

For Kubernetes users, dynamically provision Persistent Volumes with ReadWriteMany access by following instructions in the [documentation about how to use File Storage with Kubernetes Kapsule](/kubernetes/how-to/use-sfs-with-kubernetes/).

For non-Kubernetes users, attach multiple CPU or GPU Instances to a shared and fully managed file system via [the Console, the CLI](/file-storage/quickstart/), or [Terraform](https://registry.terraform.io/providers/scaleway/scaleway/latest/docs/resources/file_filesystem).

To reach the ideal level of performance for your file system use cases, refer to recommendations on [performance scaling](/file-storage/reference-content/performance-scaling/) and [selecting a compatible Instance type](/file-storage/reference-content/file-system-instance-selection/).
