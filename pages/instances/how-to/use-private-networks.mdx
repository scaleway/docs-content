[Private Networks](/vpc/concepts/#private-networks) let your Instances communicate with each other in an isolated and secure network, without going through the public internet. You can connect each Instance to one or several Private Networks to build your own network topologies.

Private Networks are layer 2 Ethernet networks that work like a local area network (LAN). Each Instance connects to a Private Network through a [Private Network interface](/instances/concepts/#private-network-interface), which has a unique media access control (MAC) address. When you attach an Instance or another resource to a Private Network, the built-in Dynamic Host Configuration Protocol (DHCP) server of the network assigns it private IP addresses.

To filter the Private Network traffic of an Instance, you can apply a stateful [security group](/instances/concepts/#security-group) to each Private Network interface. To manage Private Network interfaces as independent resources, see [Use Private Network interfaces](/instances/how-to/use-private-network-interfaces/).

<Requirements />
- A Scaleway account logged in to the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Instance](/instances/how-to/create-an-instance/)

## Create a new Private Network

Follow this procedure to create a Private Network and attach an existing Instance to it in one step.

The Private Network uses default settings, with an auto-generated [Classless Inter-Domain Routing (CIDR) block](/vpc/concepts/#cidr-block). The Private Network allocates private IP addresses to attached Instances from this CIDR block. Each Instance gets one IPv4 address and one IPv6 address on the Private Network.

To create a Private Network without attaching any resources, or with a custom CIDR block, see [Create a Private Network](/vpc/how-to/create-private-network/).

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances page](https://console.scaleway.com/instance/servers) opens.
2. Select an Availability Zone (AZ) from the dropdown, for example `PAR1`, to view the resources in that AZ.
3. Click the Instance you want to attach to a Private Network.
4. Click the **Network** tab.
5. Click **Attach to a Private Network**. A dialog box appears.
6. Click the **Select a Private Network** dropdown, then click **Create a new Private Network**.
7. Select the VPC in which to create the Private Network.
8. Enter a **Name** for the Private Network, or keep the randomly generated name.
9. Optionally, enter tags.
10. Optionally, select a **Security group** to apply to the Private Network interface of the Instance. The security group must be [stateful](/instances/concepts/#stateful-security-groups). By default, the interface has no security group.
11. Click **Attach to a Private Network**.
    The **Network** tab opens. The new Private Network appears in the list, with the private IP address of your Instance on this network. For more information, see [How to view the IP address of a resource](/vpc/how-to/attach-resources-to-pn/#how-to-view-the-resources-ip-address).

## Attach Instances to an existing Private Network

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances page](https://console.scaleway.com/instance/servers) opens.
2. Select an Availability Zone (AZ) from the dropdown, for example `PAR1`, to view the resources in that AZ.
3. Click the Instance you want to attach to the Private Network.
4. Click the **Network** tab.
5. Click **Attach to a Private Network**. A dialog box appears.
6. Select the Private Network from the dropdown.<br/>
   The dropdown lists only the Private Networks in the same region as your Instance.
7. Select the **Private Network interface** to use. Keep **Auto-allocate a Private Network interface** to create a new interface, or select an existing Private Network interface that is not attached to any Instance. If you select an existing interface, the Instance uses its private IP addresses and security group.
8. (Optional). Select a **Security group** to apply to the Private Network interface. The security group must be [stateful](/instances/concepts/#stateful-security-groups). By default, the interface has no security group.
9. If you auto-allocate a new Private Network interface, choose how to assign its IPv4 address and its IPv6 address. For each one, either auto-allocate an available IP address from the pool (the [CIDR block](/vpc/concepts/#cidr-block) defined when you created the Private Network), or use a [reserved IP address](/ipam/concepts/#reserved-ip-address).
10. Click **Attach to a Private Network**.<br/>
    The **Network** tab opens and shows the private IP address of the Instance on this Private Network. See [How to view the IP address of a resource](/vpc/how-to/attach-resources-to-pn/#how-to-view-the-resources-ip-address), for more information.

## Detach Instances from a Private Network

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances page](https://console.scaleway.com/instance/servers) opens.
2. Select an Availability Zone (AZ) from the dropdown, for example `PAR1`, to view the resources in that AZ.
3. Click the Instance you want to detach from a Private Network.
4. Click the **Network** tab.
5. Click the unlink icon <Icon name="unlink" /> next to the Private Network you want to detach. A dialog box appears.
6. Optionally, check the **Delete associated Private Network interface** box to delete the Private Network interface of the Instance on this Private Network.
    If you leave this box unchecked, Scaleway keeps the Private Network interface as an independent resource, with its private IP addresses and security group. You can [attach it to another Instance](/instances/how-to/use-private-network-interfaces/#attach-a-private-network-interface-to-an-instance) later.
7. Click **Detach** to confirm. The Private Network no longer appears in the list on the **Network** tab.

## Delete a Private Network

You delete Private Networks from the VPC section of the console. Before you delete a Private Network, [detach all its resources](/vpc/how-to/attach-resources-to-pn/#how-to-detach-a-resource-from-a-private-network). See [How to delete a Private Network](/vpc/how-to/delete-private-network/), for the full procedure.
