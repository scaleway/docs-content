This new version introduce the support for custom userdata definition.
A userdata is dedicated to a pool.

This feature introduce three interaction with userdata:
* Creating during cluster creation or dedicated pool creation ([details](https://www.scaleway.com/en/developers/api/kubernetes/pools#create-a-new-pool-in-a-cluster))
* Listing all userdata for a given pool id ([details](https://www.scaleway.com/en/developers/api/kubernetes/user-data#list-all-user-data-related-to-a-given-pool))
* Retrieving the content of an userdata ([details](https://www.scaleway.com/en/developers/api/kubernetes/user-data#get-a-pool-related-user-data))


This new feature can be use to provide a custom userdata named cloud-init.
Then this specific userdata would be read by the node during the boot time. You can found out more details about cloud-init [here](https://docs.cloud-init.io/en/latest/reference/examples.html)
