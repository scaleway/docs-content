This page provides the workflow schema used to validate YAML workflow DSL files in Scaleway Data Orchestrator.

The workflow schema is a JSON Schema that defines the exact structure that workflow DSL YAML files must follow. 
You can use it to:
- Enable autocompletion and inline validation in your code editor.
- Validate your workflow DSL files in your CI/CD pipelines.
- Understand why a workflow DSL file is rejected on upload.
- Write your workflow DSL files with a tool or agent. For LLMs and AI agents, this schema is the grammar to follow to generate valid workflow DSLs.
