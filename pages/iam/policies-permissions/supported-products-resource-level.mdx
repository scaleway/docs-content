The following table provides details about the Scaleway products that are integrated with IAM [resource-level conditions](/iam/policies-permissions/understanding-resource-level-conditions/).

## Product integration available

| **Product name**   | **Resource-level conditions integration** | **Details**                                                                                                                                     |
|---------------------|--------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| IAM                 | **Integrated**                              | Access per user, policy, application, group, SSH key, or API key. Global product. |
| Key Manager         | **Integrated**                              | Access per key (not per key version). Regional product. |
| Secret Manager      | **Integrated**                              | Access per secret (not per secret version). Regional product. Example use case: restricting access to a secret folder using `resource.name.startsWith("/folder/")`. |
| Serverless Containers | **Integrated**                            | Private access to containers, scoped by namespace. Resource-level conditions apply to the `ContainersPrivateAccess` permission set only. |
| Serverless Functions | **Integrated**                             | Private access to functions, scoped by namespace. Resource-level conditions apply to the `FunctionsPrivateAccess` permission set only. |

<Message type="note">
  For Serverless Containers and Serverless Functions, resource-level conditions apply to private access only, meaning the calls made to your private containers and functions. They do not apply to the products management APIs, such as creating, updating, or deleting containers and functions.
</Message>
