Scaleway Elastic Metal servers are on-demand, dedicated physical servers. These servers are ideal for large workloads, big data, and applications that require increased security and dedicated resources. You can install an Operating System (OS) or other [image](/elastic-metal/concepts/#image) on your Elastic Metal server and connect to it via SSH. You can power off the server when you are not using it, or delete it from your account when you no longer need it.

## Create an Elastic Metal server

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Bare Metal** > **Elastic Metal**. The Elastic Metal server creation page opens.
2. Click **Create Elastic Metal server**. The server creation wizard opens.
3. Complete the following configuration steps:
    1. Select a server from the available options.
    2. Select the geographical region for your server by choosing an Availability Zone. For a complete list of supported locations, see [Product availability by region](https://www.scaleway.com/en/product-availability-by-region/?categories=bare-metal).
    3. Select the commitment plan for your server. The following options are available:
        - **No commitment:** You can terminate the subscription of your server at any time.
        - **Commitment:** You subscribe to a [commitment plan for Elastic Metal](/elastic-metal/faq/#pricing-and-billing) and benefit from a discounted monthly price based on your choice.
          <Message type="important">
            You cannot switch from a monthly commitment to hourly billing or downgrade your commitment plan before its end. You must delete the server, wait for the end of you commitment and create a new one instead. For more information, see [How to change billing period](/elastic-metal/how-to/change-billing-period/).
          </Message>
    4. Select an OS to run on your server or opt for no pre-installed image.
    5. Configure server partitioning, with either a default configuration or [advanced partitioning](/elastic-metal/how-to/configure-disk-partitions/).
    6. (Optional) Enable and configure cloud-init. [Cloud-init](/elastic-metal/concepts/#cloud-init) is a widely adopted standard for customizing dedicated servers.
    7. Enter a name and, optionally, add tags to identify your server.
    8. Add your SSH key (required if installing an image on your server). Depending on the OS image, you may also need to configure the panel user for your server.
    9. Increase public bandwidth for your server. This option may not be available for all offers.
    10. (Optional) Enable the Private Networks feature. See the [Private Networks](/vpc/concepts/#private-networks) documentation for details.
    11. (Optional) Create up to 10 servers with the same configuration and description. 
    12. Review the estimated environmental footprint of your Elastic Metal server. For details regarding how the environmental impact of Scaleway services is calculated, see [Environmental Footprint calculator breakdown](/environmental-footprint/additional-content/environmental-footprint-calculator).
4. In the **Summary**, review the estimated cost based on your selected configuration.
5. Read and accept the terms and conditions. Whether a setup fee is included depends on the chosen billing method.
6. Click **Create Elastic Metal server** to complete your order.

You can monitor the delivery progress from the list of Elastic Metal servers in the console.

## Install an Elastic Metal server

<Message type="note">
  Follow this procedure if you created your server without a preinstalled Operating System (OS). Make sure your server status is `Ready` before proceeding.
</Message>

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Bare Metal** > **Elastic Metal**. The Elastic Metal server dashboard opens.
2. Select the Elastic Metal server you want to install from the list.
3. Click **Install** to launch the OS installation wizard.
4. Select the OS that you want to install.
5. Add your [SSH key](/organizations-and-projects/concepts/glossary/#ssh-key). If you previously [uploaded an SSH key](/iam/security/create-ssh-key/#how-to-upload-the-public-ssh-key-to-the-scaleway-interface), it appears in the list of keys.
6. Check the corresponding boxes to grant access to the server.
7. Click **Install server**.

## Power off an Elastic Metal server

<Message type="note">
  Stop your operating system by executing the `halt` command before shutting off the server. Otherwise, you risk damaging the file system and causing data loss.
</Message>

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Bare Metal** > **Elastic Metal**. The Elastic Metal server dashboard opens.
2. Click <Icon name="more" /> next to the server you want to power off.
3. Click **Power off** in the dropdown.
4. 4. Confirm that you have shut down the operating system and click **Power off Elastic Metal server** to power off the server.
