A bucket is the container in which Object Storage stores your objects (documents, images, videos, and more). You must create a bucket before you can upload objects. You can create a bucket from the [Scaleway console](https://console.scaleway.com), or with any Amazon S3-compatible tool.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A CLI tool [installed and configured](/object-storage/api-clients/cli-tools-and-clients/), if you do not use the console

## Create a bucket

The following tabs describe how to create a bucket using the console or a CLI tool. The rclone, s3cmd, and MinIO Client examples use the `scaleway` remote and alias that [the Scaleway CLI generates](/object-storage/api-clients/scaleway-cli/). Replace `<BUCKET_NAME>` with the name of your bucket.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, click **Object Storage**. The Object Storage dashboard appears.

    2. Click **Create bucket**. The bucket creation page opens.

    3. Select the [region](/object-storage/concepts/glossary/#region-and-availability-zone) in which to create your bucket.

    4. Enter a name for your bucket.

    5. Select **Public** or **Private** to define the visibility of the bucket. Bucket visibility defines whether everyone can see the list of objects in the bucket. It does not affect [object visibility](/object-storage/concepts/glossary/#visibility): an object uploaded to a public bucket is private by default, and is not publicly accessible. You can change the visibility of the bucket at any time from the **Bucket settings** tab.

    6. (Optional) Check **Enable bucket encryption** and select an encryption type:
        - [SSE-ONE](/object-storage/data-protection/sse-one/) to encrypt your objects with keys managed by Scaleway
        - [SSE-KMS](/object-storage/data-protection/sse-kms/) to encrypt your objects with keys that your Organization manages in [Key Manager](/key-manager/concepts/)

    7. (Optional) Configure [bucket versioning](/object-storage/data-protection/versioning/):
        - Check **Enable bucket versioning** to store several versions of your objects. Versioning can increase your storage costs.
        - Check **Enable object lock** to prevent the deletion or overwrite of objects for a defined retention period. Object lock requires versioning.

    8. Select a use case for your bucket.

    9. (Optional) Check **Activate 90-day free trial** to receive a total of 750 GB of free [Standard Multi-AZ and Standard One Zone](/object-storage/faq/#what-are-the-object-storage-classes-offered-by-scaleway) storage for the buckets of your Organization, across all regions. See the [Object Storage FAQ](/object-storage/faq/#how-can-i-benefit-from-the-object-storage-free-trial) for more information.

    10. (Optional) Use the cost estimator to simulate your Object Storage costs and environmental footprint.

    11. Click **Create bucket**. The **Files** tab of your new bucket opens.
  </TabsTab>
  <TabsTab label="AWS CLI">
    1. Run the following command to create a bucket in the region of your AWS CLI profile:
        ```bash
        aws s3 mb s3://<BUCKET_NAME>
        ```
        An output similar to the following appears:
        ```
        make_bucket: <BUCKET_NAME>
        ```

    2. Run the following command to list your buckets:
        ```bash
        aws s3 ls
        ```
  </TabsTab>
  <TabsTab label="rclone">
    1. Run the following command to create a bucket:
        ```bash
        rclone mkdir scaleway:<BUCKET_NAME>
        ```

    2. Run the following command to list your buckets:
        ```bash
        rclone lsd scaleway:
        ```
        An output similar to the following appears:
        ```
          -1 2022-06-04 14:38:03        -1 my-bucket
          -1 2023-12-23 12:10:57        -1 my-new-bucket
        ```
  </TabsTab>
  <TabsTab label="s3cmd">
    Run the following command to create a bucket:

    ```bash
    s3cmd mb s3://<BUCKET_NAME>
    ```

    An output similar to the following appears:

    ```
    Bucket 's3://my-bucket/' created
    ```
  </TabsTab>
  <TabsTab label="MinIO Client">
    Run the following command to create a bucket:

    ```bash
    mc mb scaleway/<BUCKET_NAME>
    ```

    An output similar to the following appears:

    ```
    Bucket created successfully `scaleway/my-bucket`.
    ```
  </TabsTab>
</Tabs>

The equivalent API call is [CreateBucket](/object-storage/api-clients/bucket-operations/#createbucket).
