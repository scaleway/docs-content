Scaleway [Elastic Metal servers](https://www.scaleway.com/en/elastic-metal/) provide on-demand dedicated servers similar to cloud instances. These servers are ideal for large workloads, big data, and applications requiring enhanced security and dedicated resources.

<Requirements />
- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- An [SSH key](/organizations-and-projects/how-to/create-ssh-key/)

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Bare Metal** > **Elastic Metal**. The Elastic Metal server creation page opens.
2. Click **Create Elastic Metal server**. The server creation wizard opens.
3. Complete the following configuration steps:
    1. Select a server from the available options.
    2. Select the geographical region for your server by choosing an Availability Zone. Currently, Elastic Metal servers are available in:
        - Amsterdam, Netherlands (`AMS-1`, `AMS-2`)
        - Paris, France (`PAR-1`, `PAR-2`)
        - Warsaw, Poland (`WAW-2`, `WAW-3`)
    3. Select the commitment plan for your server. The following options are available:
        - **No commitment:** You can terminate the subscription of your server at any time.
        - **Commitment:** You subscribe to a [commitment plan for Elastic Metal](/elastic-metal/faq/#pricing-and-billing) and benefit from a discounted monthly price based on your choice.
          <Message type="important">
            You cannot switch from a monthly commitment to hourly billing or downgrade your commitment plan before its end. You must delete the server and create a new one instead. For more information, see [How to change billing period](/elastic-metal/how-to/change-billing-period/).
          </Message>
    4. Select an OS to run on your server or opt for no pre-installed image.
    5. (Optional) Enable and configure cloud-init. [Cloud-init](/elastic-metal/concepts/#cloud-init) is a widely adopted standard for customizing dedicated servers.
    6. Configure server partitioning, with either a default configuration or [advanced partitioning](/elastic-metal/how-to/configure-disk-partitions/).
    7. Increase public bandwidth for your server. This option may not be available for all offers.
    8. (Optional) Enable the Private Networks feature. See [Private Networks](/vpc/concepts/#private-networks) documentation for details.
    9. Add your SSH key (required if installing an image on your server). Depending on the OS image, you may also need to configure the panel user for your server.
    10. Enter a name and, optionally, add tags to identify your server.
    11. (Optional) Create up to 10 servers with the same configuration and description. 
    12. Review the estimated environmental footprint of your Elastic Metal server.
      <Message type="note">
        For details regarding how the environmental impact of Scaleway services is calculated, see [Environmental Footprint calculator breakdown](/environmental-footprint/additional-content/environmental-footprint-calculator).
      </Message>
4. In the **Summary**, review the estimated cost based on your selected configuration.
5. Read and accept the terms and conditions. Whether a setup fee is included depends on the chosen billing method.
6. Click **Create Elastic Metal server** to complete your order.

You can monitor the delivery progress from the list of Elastic Metal servers in the console.
