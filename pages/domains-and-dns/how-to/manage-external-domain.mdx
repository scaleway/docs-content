Once your external domains have been created and validated, you can manage them from the Scaleway console.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- [Linked your domain](/domains-and-dns/how-to/add-external-domain/) with Scaleway Domains and DNS

## Add a new DNS zone

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Domains and DNS**. The Domains and DNS page opens.
2. Click the domain for which you want to add a DNS zone. The **Overview** tab opens.
3. Click the **DNS zones** tab. A list of the DNS zones you have configured within the selected domain appears.
    <Message type="note">
      The **Root zone** is available by default. This zone is directly associated with the domain name and cannot be deleted. It is only removed from the DNS when you delete the associated domain name.
    </Message>
4. Click **+ Add zone** to create a new DNS zone. A dialog box appears prompting you to enter a name for the new DNS zone.
5. Enter a name, check the estimated cost, and click **Add zone**.

## Delete an existing DNS zone

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Domains and DNS**. The Domains and DNS page opens.
2. Click the domain for which you want to delete a DNS zone. The **Overview** tab opens.
3. Click the **DNS zones** tab. A list of the DNS zones you have configured within the selected domain appears.
4. Click <Icon name="more" /> next to the DNS zone you want to delete, then click **Delete**.
5. Type **DELETE** and click **Delete zone** to confirm the action.


## Add DNS records

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Domains and DNS**. The Domains and DNS page opens.
2. Click the domain you want to manage. The **Overview** tab opens.
3. Click the **DNS zones** tab. A list of the DNS zones you have configured within the selected domain appears.
4. Click the DNS zone you want to add a record to.
5. Click **+ Add records**. A dialog box appears.
6. Fill in the required information for the record.
7. Click **Add records** to confirm.

## Delete DNS records

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Domains and DNS**. The Domains and DNS page opens.
2. Click the domain you want to manage. The **Overview** tab opens.
3. Click the **DNS zones** tab. A list of the DNS zones you have configured within the selected domain appears.
4. Click the DNS zone containing the record you want to delete. The list of records within the selected zone appears.
5. Click <Icon name="delete" /> next to the record you want to delete. A dialog box appears.
6. Type **DELETE** to confirm.
7. Click **Delete record** to delete the record from the zone.

## Terminate domain management

<Message type="warning">
  This action is irreversible and will permanently revoke your external domain management and delete its DNS zones.
</Message>

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Domains and DNS**. The Domains and DNS page opens.
2. Click the domain you want to manage. The **Overview** tab opens.
3. Click the **Settings** tab.
4. Click **Terminate management**. A dialog box appears.
5. Type **DELETE** to confirm.
6. Click **Terminate domain management**.
