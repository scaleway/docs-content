[Snapshots](/managed-databases-for-postgresql-and-mysql/concepts/#database-snapshot) save the state of a Database Instance so you can restore its data to a new Database Instance. Snapshots are available only for Database Instances that use Block Storage. You can create snapshots manually or let autobackup create them on a schedule.

You can have up to 100 snapshots per Database Instance and Project, depending on your quotas. To create a new Database Instance from a snapshot, see [How to create a Database Instance from a snapshot](/managed-databases-for-postgresql-and-mysql/how-to/create-a-database/#how-to-create-a-database-instance-from-a-snapshot).

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- A [PostgreSQL or MySQL Database Instance](/managed-databases-for-postgresql-and-mysql/quickstart/)

## Create a snapshot

Your Database Instance must be in the `READY` state before you create a snapshot.

1. Click the **Snapshots** tab of your Database Instance.
2. Click **Create snapshot**. A dialog box appears.
3. Enter a name for your snapshot and set its expiration date and time. The default retention period is 7 days.
4. Click **Create snapshot** to confirm.

## Configure automated snapshots

For Database Instances that use Block Storage, autobackups are created as snapshots. Automated snapshots are not subject to quota limitations. See the [Managed Databases FAQ](/managed-databases-for-postgresql-and-mysql/faq/#why-is-my-number-of-active-backupssnapshots-exceeding-the-quota) for more information.

1. In the side menu, under **Databases**, click **PostgreSQL and MySQL**. The list of your Database Instances appears.
2. Select the region of your Database Instance from the dropdown.
3. Click the name of your Database Instance, or click <Icon name="more" /> > **More info**. The Database Instance's **Overview** page opens.
4. Click the **Settings** tab.
5. In the **Snapshot configuration** section, click **Edit**.
6. Select **Automated**.
7. Select the frequency and retention period.
8. Click <Icon name="validate" /> to confirm.

<Message type="note">
  The base time for automated snapshots is when you created the Database Instance. When you change the schedule, it becomes the time you confirmed the change. For example, if you set the frequency to every day at 08:00 on a Thursday, the next snapshot happens at 08:00 on Friday.
</Message>

## Delete a snapshot

Deleting a Database Instance does not delete its snapshots. Scaleway deletes snapshots at the end of their retention period. You can also delete snapshots manually.

<Message type="important">
  Deleting a snapshot is irreversible. It permanently deletes the snapshot and all its data.
</Message>

1. Click the **Snapshots** tab of your Database Instance.
2. Click <Icon name="more" /> > **Delete** next to the snapshot you want to delete. A dialog box appears.
3. Type **DELETE** in the confirmation field.
4. Click **Delete snapshot** to confirm.
