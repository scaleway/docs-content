Object visibility defines whether anyone with the link can access an object over HTTPS, independently from [bucket visibility](/object-storage/concepts/glossary/#visibility). All objects are private by default, even in a public bucket, and a private object in a public bucket is not publicly accessible.

To share an object, you can either make it public and share its permanent link, or keep it private and generate a temporary link that expires after a set duration.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Object Storage bucket](/object-storage/buckets/create-a-bucket/) containing [objects](/object-storage/objects/upload-objects/)
- The [AWS CLI](/object-storage/api-clients/cli-tools-and-clients/) installed and configured, if you use the CLI

## Change the visibility of an object

The following tabs describe how to make a single object public or private using the console or the AWS CLI.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of your bucket. The list of your objects appears.

    3. Click <Icon name="more" /> next to the name of the object.

    4. Click **Visibility**. A dialog box appears.

    5. Select **Public** or **Private**.

    6. Click **Update object visibility** to confirm.
  </TabsTab>
  <TabsTab label="AWS CLI">
    Run the following command to make an object public. Replace the placeholders with the appropriate values.

    ```bash
    aws s3api put-object-acl --bucket <BUCKET_NAME> --key <OBJECT_KEY> --acl public-read
    ```

    To make the object private again, run the same command with `--acl private`. You can also make an object public when you upload it, by adding the `--acl public-read` option to the `aws s3 cp` command.

    The equivalent API call is [PutObjectAcl](/object-storage/api-clients/object-operations/#putobjectacl).
  </TabsTab>
</Tabs>

[Bucket policies](/object-storage/access-control/bucket-policies/) take precedence over object ACLs.

## Make several objects public with a bucket policy

To manage the visibility of several objects at a time, use a [bucket policy](/object-storage/access-control/bucket-policies/). The following policy allows [GetObject](/object-storage/api-clients/object-operations/#getobject) operations to everyone on the objects with the `public-objects/` prefix, so that anyone with the link can access them.

```json
{
  "Id": "object-visibility",
  "Version": "2023-04-17",
  "Statement": [
    {
      "Sid": "make-objects-visible",
      "Principal": "*",
      "Action": [
        "s3:GetObject"
      ],
      "Effect": "Allow",
      "Resource": [
        "my-bucket/public-objects/*"
      ]
    }
  ]
}
```

See [How to manage bucket policies](/object-storage/access-control/manage-bucket-policies/) to apply the policy.

## Share an object over HTTPS

The link to a public object is permanent, and works as long as the object is public. For a private object, generate a temporary link that grants access until its expiration.

The following tabs describe how to retrieve or generate the link to an object using the console or the AWS CLI.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of the bucket that contains the object. The list of your objects appears.

    3. Click <Icon name="more" /> next to the object.

    4. Click **Get public link**.

    5. Set an expiration date.

    6. Click **Generate link**. Your temporary public link appears.
  </TabsTab>
  <TabsTab label="AWS CLI">
    Run the following command to generate a presigned URL for a private object. Replace `<EXPIRATION>` with the validity of the link in seconds, for example `3600` for 1 hour.

    ```bash
    aws s3 presign s3://<BUCKET_NAME>/<OBJECT_KEY> --expires-in <EXPIRATION>
    ```

    The command returns a URL that anyone can use to download the object until the link expires.
  </TabsTab>
</Tabs>

If a temporary link returns an error, see [I cannot access my buckets or objects](/object-storage/troubleshooting/access-and-authentication/#i-get-presigned-url-errors).
