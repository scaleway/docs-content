[Standby mode](/instances/concepts/#standby-mode) temporarily stops an Instance. The Instance remains allocated to your account, and all data remains on its Local Storage and [scratch storage](/instances/reference-content/understanding-scratch-storage/).

To stop an Instance that uses scratch storage without losing its scratch data, use standby mode instead of [powering off](/instances/how-to/power-off-instance/) the Instance.

<Requirements />
- A Scaleway account logged in to the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Instance](/instances/how-to/create-an-instance/)

<Message type="important">
  Scaleway continues to bill an Instance in standby mode, as well as its storage and its flexible IP addresses. To stop being billed for the compute resources of an unused Instance, [power it off](/instances/how-to/power-off-instance/) instead. 
  
  See [When does the billing of a resource start and stop?](/billing/faq/#when-does-the-billing-of-a-resource-start-and-stop) for more information.
</Message>

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you want to switch to standby mode. The **Overview** page of the Instance opens.
4. Scroll down to the **Standby mode** section.
    <Lightbox image={image} alt="The Standby mode section of the Instance Overview page, with the Switch to standby mode button" />
5. Click **Switch to standby mode**. A dialog box appears asking you to confirm the action.
6. Click **Switch Instance to standby mode**. The Instance switches to standby mode.
You can also switch your Instance to standby mode from inside the Instance. Run the `poweroff` command to shut down the OS, which switches the Instance to standby mode.
