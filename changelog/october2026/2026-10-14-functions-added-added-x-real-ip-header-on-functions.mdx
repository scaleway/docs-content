status: added
date: 2026-10-14
category: serverless
product: functions
---

Use the `X-Real-IP` header to identify the IP address of the client. It contains the list of IP addresses the request has passed through, with the original client IP as the first entry.

For more information, see the [dedicated documentation](/serverless-functions/reference-content/request-headers/).
