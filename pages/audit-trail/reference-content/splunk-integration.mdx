Audit Trail supports sending event data to Splunk Enterprise and Splunk Cloud Platform for security monitoring, data visualization and analytics, and compliance reporting.

By centralizing Scaleway audit data within Splunk, security operations center (SOC) and cloud operations teams can address several operational and security use cases:
- User activity monitoring and access governance
- Change tracking and configuration management
- Compliance auditing and reporting (SOC 2, ISO 27001)
- Security incident investigation and forensics
- Anomaly detection and threat hunting
- Operational troubleshooting and root cause analysis

This guide explains how to integrate Scaleway Audit Trail with Splunk.

The integration consists of two components, both installable and configurable via Splunk:

- Scaleway Add‑on for Splunk – Collects Audit Trail events from your Scaleway infrastructure and forwards them securely to Splunk Enterprise/Cloud.
- Scaleway App for Splunk – Visualizes the ingested events with ready‑made dashboards and security analytics; you can also build custom dashboards.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- API credentials (Access Key ID and Secret Key) with Audit Trail read permissions
- Splunk Enterprise or Splunk Cloud Platform (supported versions: 9.4.x, 10.0.x, 10.2.x, 10.4.x)

## Scaleway Add-on for Splunk

### Overview

The Scaleway Add-On for Splunk acts as a data collection layer that ingests audit logs from Scaleway infrastructure into a Splunk deployment. It connects to Scaleway accounts via API credentials, allowing administrators to collect:
- audit events from the Scaleway Audit Trail service
- IAM logs covering users, groups, and applications

Administrators can customize their setup and configure:
- multiple Scaleway Organizations to include in the scope of data collection
- polling intervals to specify the granularity of data collection intervals

To ensure compatibility across the Splunk ecosystem, the add-on extracts fields aligned with the Common Information Model (CIM). This standardized mapping allows the collected data to feed directly into Splunk Enterprise Security (ES), Splunk IT Service Intelligence (ITSI), or custom correlation searches and dashboards.

### Install the add-on

Follow these steps to install the Scaleway Add-on for Splunk:

1. In your Splunk instance, on the **Apps** homepage, click **Find more apps** in the side menu. Alternatively, go to [splunkbase](https://splunkbase.splunk.com/) and use the search functionality.
2. Search for "Scaleway Add-on". The add-on is displayed in the search results pane.
3. Click **Install**, and follow the on-screen prompts.
4. Restart Splunk when prompted.

    Once in Splunk, navigate to **Apps**. You should see the **Scaleway Add-on** in the list of apps.

### Configure and use the add-on

Follow these steps to configure the Scaleway Add-on for Splunk:

1. In your Splunk instance, navigate to **Apps** > **Scaleway Add-on**. The **Configuration** tab of the add-on opens.
2. Configure a Scaleway Organization and API key.
    1. On the **Configuration** tab, click the **Accounts** tab.
    3. Click the **Add** button. The **Add Accounts** window appears.
          <Lightbox image={image1} alt="A screenshot showing the Add Accounts window in Splunk" size="large" />
    4. Provide the required information in the fields marked with an asterisk:
        - **Account name**: Any descriptive name that helps you identify the account. 
        - **Organization ID**: The identifier of your Organization in Scaleway. You can retrieve your Organization ID from the Scaleway console: select **Organization Dashboard** in the side menu, then click **Copy ID**.
        - **SCW Secret Key**: The API Secret Key that your Scaleway account will use to authenticate to Splunk. When you [create your Scaleway API key in the Scaleway console](/iam/how-to/create-api-keys/), you are provided an Access Key ID and a Secret Key. The Secret Key is shown only once, make sure that you save it in a secure place.
    5. Repeat these steps for all the Organizations that you want Splunk to collect data from.
2. Specify the Audit Trail event or IAM log type that you want Splunk to ingest for data collection.
    1. Go to the **Inputs** tab and click the **Create New Input** button.
          <Lightbox image={image2} alt="A screenshot showing the Create New Input button and drop-down list in Splunk" size="large" />
    2. Select an event type from the drop-down list. A window appears prompting you to enter details for your input.
    3. Provide the required information (e.g., polling interval, Scaleway region) in the fields marked with an asterisk.

        Note that the minimum allowed polling interval is 1 poll every 60 seconds.

## Scaleway App for Splunk

### Overview

The Scaleway App for Splunk is a visualization layer built for Scaleway Audit Trail data. While the add-on handles raw data collection, the application provides pre-built dashboards for security monitoring, with the option to create custom dashboards. It also records user access patterns and maintains chronological logs of resource changes to assist with event correlation. Built-in alerting logic notifies administrators when specific anomalies or high-risk configuration changes are detected.

### Install the app

Before installing the Scaleway App, ensure the following:

- Scaleway Add-On for Splunk is installed and configured
- Audit Trail data is flowing into Splunk

Follow these steps to install the Scaleway App for Splunk:

1. In your Splunk instance, on the **Apps** homepage, click **Find more apps** in the side menu. Alternatively, go to [splunkbase](https://splunkbase.splunk.com/) and use the search functionality. 
2. Search for "Scaleway App". The app is displayed in the search results pane.
3. Click **Install**, and follow the on-screen prompts.
4. Restart Splunk when prompted.

    Once in Splunk, navigate to **Apps**. You should see the **Scaleway App** in the list of apps.

### Configure and use the app

After installation:

- Review pre-built dashboards and their configuration
- Start building your own dashboards and alerting
- Search events

#### Pre-built dashboards

To access the pre-built dashboards, access Splunk and navigate to **Apps** > **Scaleway App**. The **Scaleway - Data pipeline health status** dashboard opens. 

To switch between dashboards, use the side menu.

The following pre-built dashboards are available:
- **Scaleway - Data pipeline health status**: Displays data ingestion and event count metrics, as well as errors for the Scaleway audit data feed
- **Scaleway - Authentication monitoring**: Tracks login events, session details, credential usage, with options to filter by user
- **Scaleway - Activity monitoring**: Focuses on dividing views between account management actions (such as account creation, update, and deletion) and asset management events (such as methods used, successful and failed operations)

#### Custom dashboards and alerting

In addition to using the pre-built dashboards, you can also add your own custom dashboards and alerting.

For detailed guidance, consult the [Splunk Enterprise documentation](https://help.splunk.com/en/splunk-enterprise) or the [Splunk Cloud Platform documentation](https://help.splunk.com/en/splunk-cloud-platform/).
