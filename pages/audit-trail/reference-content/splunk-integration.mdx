This page explains how to integrate Scaleway Audit Trail with Splunk Enterprise and Splunk Cloud platforms for centralized security monitoring and compliance reporting.

The integration consists of two components:

- Scaleway Add-on for Splunk (backend) - Collects and ingests Audit Trail logs from Scaleway infrastructure into your Splunk deployment
- Scaleway App for Splunk (frontend) - Provides pre-built dashboards and analytics for visualizing Audit Trail data

By centralizing Scaleway audit data within Splunk, security operations center (SOC) and cloud operations teams can address several operational and security use cases:
- Security incident investigation and forensics
- Compliance auditing and reporting (SOC 2, ISO 27001, GDPR, PCI-DSS)
- User activity monitoring and access governance
- Change tracking and configuration management
- Anomaly detection and threat hunting
- Operational troubleshooting and root cause analysis

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- Active Scaleway account with Audit Trail enabled
- API credentials (Access Key ID and Secret Key) and with Audit Trail read permissions
- Splunk Enterprise or Splunk Cloud platform (supported versions: 9.4.x, 10.0.x, 10.2.x, 10.4.x)

## Scaleway Add-on for Splunk

### Overview

The Scaleway Add-On for Splunk acts as a data collection layer that ingests audit logs from Scaleway infrastructure into a Splunk deployment. It connects to Scaleway accounts via API credentials, allowing administrators to collect:
- audit events from the Scaleway Audit Trail service
- IAM logs covering users, groups, and applications

Administrators can customize their setup and configure:
- multiple Scaleway Organizations to include in the scope of data collection
- polling intervals to specify the granularity of data collection intervals

To ensure compatibility across the Splunk ecosystem, the add-on extracts fields aligned with the Common Information Model (CIM). This standardized mapping allows the collected data to feed directly into Splunk Enterprise Security (ES), Splunk IT Service Intelligence (ITSI), or custom correlation searches and dashboards.

### Install the add-on

Follow these steps to install the Scaleway Add-on for Splunk:

1. In Splunk {/* EDITORIAL COMMENT: What is the link? */}, click **Find more apps** in the side menu.
2. Search for "Scaleway Add-on". The add-on is displayed in the search results pane.
3. Click **Install**, and follow the on-screen prompts.
4. Restart Splunk when prompted.
    Navigate to **Apps** and you should see the **Scaleway Add-on** in the list.

### Configure the add-on

Follow these steps to configure the Scaleway Add-on for Splunk:

1. In Splunk {/* EDITORIAL COMMENT: What is the link? */}, navigate to **Apps** > **Scaleway Add-on**. The **Configuration** tab of the add-on opens.
2. Configure a Scaleway Organization and API key.
    1. On the **Configuration** tab, click the **Accounts** tab.
    3. Click the **Add** button. The **Add Accounts** window appears.
    4. Provide the following information:
        - Account name: Any descriptive name that helps you identify the account. 
        - Organization ID: The identifier of your Organization in Scaleway. You can retrieve your Organization ID from the Scaleway console: select **Organization Dashboard** in the side menu, then click **Copy ID**.
        - SCW Secret Key: The API Secret Key that your Scaleway account will use to authenticate to Splunk. When you [create your Scaleway API key in the Scaleway console](/iam/how-to/create-api-keys/), you are provided an Access Key ID and a Secret Key. The Secret Key is shown only once, make sure that you save it in a secure place.
    5. Repeat these steps for all the Organizations that you want Splunk to collect data from.
2. Specify the Audit Trail event or IAM log type that you want Splunk to ingest for data collection.
    1. Go to the **Inputs** tab and click the **Create New Input** button.
    2. Select an event type from the drop-down list. A window appears prompting you to enter details for your input. {/* EDITORIAL COMMENT: Shall we provide a definition for each item in the list? */}
    3. Provide the required information, such as polling interval and Scaleway region, in the fields marked with an asterisk.

      <Message type="tip">
      - To retrieve your **Project ID**. go to the Scaleway console, select **Project Dashboard** in the side menu, then click **Copy ID**.
      - To retrieve a **Product name**, go to the Scaleway console, select **Monitoring > Audit Trail** in the side menu. The Audit Trail dashboard opens. On the **Events** tab, select the **Product** field. A drop-down list appears. Use the product name as displayed in the drop-down list.
      </Message>

Once configured, the Scaleway Add-on continuously polls Scaleway Audit Trail APIs at the specified interval and forwards events to Splunk for indexing and analysis.

## Scaleway App for Splunk

### Overview

The Scaleway App for Splunk is a visualization layer built for Scaleway Audit Trail data. While the add-on handles raw data collection, the application provides pre-built dashboards for security monitoring, displaying incoming audit events as they are ingested. It also records user access patterns and maintains chronological logs of resource changes to assist with event correlation. Built-in alerting logic notifies administrators when specific anomalies or high-risk configuration changes are detected.

### Install the app

Before installing the Scaleway App, ensure the following:

- Scaleway Add-On for Splunk is installed and configured
- Audit data is flowing into Splunk

Follow these steps to install the Scaleway App for Splunk:

1. In Splunk {/* EDITORIAL COMMENT: What is the link? */}, click **Find more apps** in the side menu.
2. Search for "Scaleway App". The app is displayed in the search results pane.
3. Click **Install**, and follow the on-screen prompts.
4. Restart Splunk when prompted.
    Navigate to **Apps** and you should see the **Scaleway App** in the list.

### Configure and use the app

After installation:

- Review pre-built dashboards and their configuration
- Start building your own dashboards and alerting
- Search

To access the pre-built dashboards, navigate to **Apps** > **Scaleway App**. The **Scaleway - Data pipeline health status** dashboard opens. To switch between dashboards, use the side menu.

The application provides the following pre-built dashboards:
- **Scaleway - Data pipeline health status**: IMPROVE Monitors the health status of the Scaleway data pipeline
- **Scaleway - Authentication monitoring**: Tracks login events, session details, credential usage, and specific monitored user activity
- **Scaleway - Activity monitoring**: Focuses on infrastructure operations, dividing views between account management actions (such as IAM policy updates) and asset management events (such as resource creation, modification, or deletion)
