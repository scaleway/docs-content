When you delete a bucket, Object Storage also deletes every object and version stored in it. You can delete a bucket from the [Scaleway console](https://console.scaleway.com), or with any Amazon S3-compatible tool.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Object Storage bucket](/object-storage/buckets/create-a-bucket/)
- A CLI tool [installed and configured](/object-storage/api-clients/cli-tools-and-clients/), if you do not use the console

## Delete a bucket

<Message type="important">
- Deleting a bucket permanently deletes all its objects and versions. The bucket name then becomes available to other users.
- When you delete a bucket from the console, the effective deletion starts 24 hours after your request. Billing stops as soon as you confirm the deletion, and the bucket, its objects, and its versions no longer appear in the console or the APIs. To make the deletion effective immediately, delete all objects and versions of the bucket before you delete it.
</Message>

The following tabs describe how to delete a bucket using the console or a CLI tool. The rclone, s3cmd, and MinIO Client examples use the `scaleway` remote and alias that [the Scaleway CLI generates](/object-storage/api-clients/scaleway-cli/). Replace `<BUCKET_NAME>` with the name of your bucket.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of the bucket.

    3. Click the **Bucket settings** tab.

    4. At the bottom of the page, click **Delete bucket**. A dialog box appears.

    5. Type **DELETE**, then click **Delete bucket**. The bucket no longer appears in your bucket list.

    You can also delete a bucket from your bucket list, by clicking <Icon name="more" /> next to its name, then **Delete**.

    The deletion of files larger than 1 GB can take longer.
  </TabsTab>
  <TabsTab label="AWS CLI">
    1. Run the following command to delete all the objects of the bucket, then the bucket:
        ```bash
        aws s3 rb s3://<BUCKET_NAME> --force
        ```
        If versioning is enabled on the bucket, delete all object versions and delete markers first, as the command fails on a bucket that still contains versions.

    2. Run the following command to check that the bucket no longer appears in your bucket list:
        ```bash
        aws s3 ls
        ```
  </TabsTab>
  <TabsTab label="rclone">
    1. Run the following command to delete the bucket and all its objects:
        ```bash
        rclone purge scaleway:<BUCKET_NAME>
        ```

    2. Run the following command to check that the bucket no longer appears in your bucket list:
        ```bash
        rclone lsd scaleway:
        ```
  </TabsTab>
  <TabsTab label="s3cmd">
    1. Run the following command to delete the bucket:
        ```bash
        s3cmd rb s3://<BUCKET_NAME>
        ```

    2. Run the following command to check that the bucket no longer appears in your bucket list:
        ```bash
        s3cmd ls
        ```
  </TabsTab>
  <TabsTab label="MinIO Client">
    1. Run the following command to delete the bucket:
        ```bash
        mc rb scaleway/<BUCKET_NAME>
        ```

    2. Run the following command to check that the bucket no longer appears in your bucket list:
        ```bash
        mc ls scaleway
        ```
  </TabsTab>
</Tabs>

The equivalent API call is [DeleteBucket](/object-storage/api-cli/bucket-operations/#deletebucket).

If you cannot delete a bucket, see [I cannot delete my data or I am billed for objects I cannot see](/object-storage/troubleshooting/deletion-and-billing/).
