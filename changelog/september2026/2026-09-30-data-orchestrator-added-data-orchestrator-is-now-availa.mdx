Data Orchestrator lets you build and run end-to-end workflows across the full Serverless portfolio: Jobs, Functions, and Containers. You can also trigger external tasks and pipelines using HTTP calls.
Design your DAGs in the live visual builder or as code, then monitor your workflow runs directly in the Scaleway console.
