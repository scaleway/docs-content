<Message type="important">
  Scratch storage is not persistent. The following actions permanently erase all data stored on the scratch volumes of an Instance:
  - Powering off the Instance
  - Changing the offer type of the Instance (resizing)
  - Deleting the scratch volume or the Instance

  Scaleway does not back up scratch storage, and you cannot snapshot it or include it in an image. Store any data you need to keep on a [Block Storage](/block-storage/) volume or in an [Object Storage](/object-storage/) bucket.
</Message>
