Two new Billing API endpoints have been added: 

- [List invoice lines](https://www.scaleway.com/en/developers/api/billing/invoices#list-invoice-lines)
- [List discount lines](https://www.scaleway.com/en/developers/api/billing/invoices#list-discount-lines)

These endpoints allow you to get the detailed line-by-line information of a specific invoice and the associated discounts.
