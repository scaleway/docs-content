In Data Orchestrator, cron schedules are attached to a workflow definition, and automatically start a new run of the workflow at each scheduled time. See [Schedule a workflow](/data-orchestrator/how-to/schedule-workflow/) for more information.

## Time zones

Data Orchestrator allows modifying the time zone of their schedules when creating or editing a workflow schedule. See [Schedule a workflow](/data-orchestrator/how-to/schedule-workflow/) for more information.
