---
title: Kubernetes Kapsule adds support for user-data
status: added
date: 2026-08-28
category: containers
product: kubernetes
---

You can now define custom user-data dedicated to a pool. This enables you to specify cloud-init configuration relying on custom user-data, which your node can then read at boot time. For more details, see the [cloud-config examples] in the cloud-init documentation.

Key interactions with user-data:
* Define user‑data when you create a cluster or a dedicated pool ([details](https://www.scaleway.com/en/developers/api/kubernetes/pools#create-a-new-pool-in-a-cluster))
* List all user-data for a given pool id ([details](https://www.scaleway.com/en/developers/api/kubernetes/user-data#list-all-user-data-related-to-a-given-pool))
* Retrieve the content of a particular user-data entry ([details](https://www.scaleway.com/en/developers/api/kubernetes/user-data#get-a-pool-related-user-data))

Use user-data named "cloud-init" with caution, overriding some configurations can break nodes.
Scaleway does not offer support for troubleshooting your cloud-init specific script.
