IP Address Manager (IPAM) is Scaleway's tool for planning, tracking and managing the IP address space of Scaleway products. It acts as a single source of truth for the IP addresses of Scaleway resources.

This page shows you how to list and filter your [public](/ipam/concepts/#public-flexible-ip-address) and [private IP addresses](/ipam/concepts/#private-ip-address) using the Scaleway console.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- At least one [reserved IP address](/ipam/how-to/reserve-ip/), or at least one resource [attached to a Private Network](/vpc/how-to/attach-resources-to-pn/)

## List and filter your IP addresses

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Select the desired region using the drop-down menu at the top of the page.

3. Select the **source** of the addresses to display:

    - **Private IPs**: private addresses on your Private Networks. Select a **VPC**, and optionally a **Private Network**, to display them.
    - **Public zonal IPs**: public addresses scoped to a single Availability Zone. Select a **zone** to display them.
    - **Public regional IPs**: public addresses scoped to the whole selected region.

    <Message type="tip">
    When viewing a private IP address in IPAM, it is shown in [CIDR notation](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing#CIDR_notation). For example, the address `172.16.12.2/22` represents the IPv4 address `172.16.12.2` and its associated CIDR block `172.16.12.0/22`, defined on the [Private Network](/vpc/how-to/create-private-network/#how-to-configure-cidr) and containing 1024 addresses.
    </Message>

4. Use the other filters for each source to refine your search, or click **All filters** to display the full set of filters available for the selected source.
