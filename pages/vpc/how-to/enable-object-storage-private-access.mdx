## How to enable Object Storage private access on a VPC

<Message type="note">
Enabling Object Storage private access on a VPC triggers billing for the feature.
</Message>

1. Enable Object Storage private access on the VPC, listing the Private Networks to authorize:

    ```bash
    curl -X POST \
      -H "X-Auth-Token: $SCW_SECRET_KEY" \
      -H "Content-Type: application/json" \
      -d '{"private_network_ids":["example-7363-616c-6577-61792e636f6d"]}' \
      "https://api.scaleway.com/vpc/v2/regions/{region}/object-storage-private-access/{vpc_id}/enable"
    ```

2. Add another Private Network, if needed:

    ```bash
    curl -X POST \
      -H "X-Auth-Token: $SCW_SECRET_KEY" \
      -H "Content-Type: application/json" \
      -d '{"private_network_id":"6170692e-7363-616c-6577-61792e636f6d"}' \
      "https://api.scaleway.com/vpc/v2/regions/{region}/object-storage-private-access/{vpc_id}/private-networks"
    ```

Refer to the [VPC API documentation](https://www.scaleway.com/en/developers/api/vpc/object-storage-private-access/) for more information.

## How to reach a bucket over the VPC endpoint

Resources in an authorized Private Network reach Object Storage privately only when they target the VPC endpoint. A client configured with the public endpoint keeps sending its requests over the public internet.

1. Connect to a resource attached to an authorized Private Network of the VPC.
2. Point your Object Storage client at the VPC endpoint of the region. For the AWS CLI, set the `endpoint_url` in your `~/.aws/config` file:

    ```
    [default]
    region = fr-par
    output = json
    services = scw-fr-par

    [services scw-fr-par]
    s3 =
      endpoint_url = https://s3-vpc.fr-par.scw.eu
    ```

3. List the contents of your bucket, replacing `<BUCKET_NAME>` with the name of your bucket:

    ```bash
    aws s3 ls s3://<BUCKET_NAME>
    ```

    The same command run from a machine outside the VPC fails, as the VPC endpoint is not reachable from the public internet.

## How to restrict bucket access to a VPC

Object Storage private access adds a private path, and applies no restriction at bucket level. Access to a bucket remains governed by [IAM permissions](/object-storage/api-cli/combining-iam-and-object-storage/) and by its [bucket policy](/object-storage/api-cli/bucket-policy/). This step is therefore optional: use it when you want a bucket to accept requests coming from your VPC only.

To do so, apply a bucket policy with the `StringEquals` condition operator and the `aws:SourceVpc` condition key.

<ImportantBucketPolicy />

1. Click **Object Storage** in the **Storage** section of the [Scaleway console](https://console.scaleway.com/) side menu. The list of your buckets displays.
2. Click the name of the bucket, then click the **Bucket policy** tab.
3. Create a bucket policy that allows access from your VPC only:

    ```json
    {
      "Version": "2023-04-17",
      "Id": "MyBucketPolicy",
      "Statement": [
        {
          "Sid": "AllowAccessFromSpecificVPC",
          "Effect": "Allow",
          "Principal": "*",
          "Action": ["s3:ListBucket", "s3:GetObject"],
          "Resource": ["<BUCKET_NAME>", "<BUCKET_NAME>/*"],
          "Condition": {
            "StringEquals": {
              "aws:SourceVpc": "<VPC_ID>"
            }
          }
        }
      ]
    }
    ```

4. Replace the `<BUCKET_NAME>` and `<VPC_ID>` placeholders with the name of your bucket and the ID of your VPC.
5. Save the bucket policy.

<Message type="important">
A statement with an `aws:SourceVpc` condition does not make a bucket private by itself: any other statement of the policy that allows the request still grants access. Review the whole policy to make sure no other statement allows requests coming from outside the VPC.
</Message>

<Message type="note">
See the [bucket policies overview](/object-storage/api-cli/bucket-policy/) for more information on the syntax and the elements of a bucket policy.
</Message>

## Key considerations

### Buckets remain publicly reachable by default

Enabling the feature on a VPC restricts nothing. Every bucket keeps its public endpoint, and its existing permissions apply unchanged. Use a bucket policy to reject requests coming from outside the VPC.

### The Scaleway console accesses buckets over the internet

When a bucket policy restricts access to a VPC ID, the Scaleway console can no longer display the objects, metrics, or logs of that bucket. Plan a management method from inside the VPC before applying such a policy.

### Bucket policies cannot target a single Private Network

You select which Private Networks of the VPC reach the VPC endpoint, but a bucket policy cannot target a specific Private Network: the `aws:SourceVpc` condition key recognizes the ID of the VPC only.
