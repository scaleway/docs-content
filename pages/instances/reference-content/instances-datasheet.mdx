This datasheet provides a concise overview of the performance, technical features, components, materials, and associated documentation for different Instance offers.

<Message type="note">
- **vCPU type** indicates whether the Instance uses [dedicated or shared vCPUs](/instances/reference-content/choosing-shared-vs-dedicated-cpus/).
- **Network bandwidth** shows two values. **Public** is the maximum bandwidth available for internet traffic. **Internal** is the maximum bandwidth available for traffic within Private Networks. Both share the same physical network interface.
- **Water usage** is only listed for zones where data is available.
</Message>
