---
title: SCIM - User groups are now supported
status: added
date: 2026-08-18
category: security-identity
product: iam
---

SCIM user provisioning now supports user groups.

If you use Entra ID, enable group provisioning from **Attribute Mapping** in the **Manage** menu. Select **Provision Microsoft Entra ID Groups**, then set **Enabled** to **Yes**.

Nested groups are not supported.
