You can create and manage databases for your website and applications, including user creation and password updates directly from the Scaleway console.


<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- [Registered a domain name](/domains-and-dns/how-to/register-internal-domain/) at Scaleway or another registrar
- A Web Hosting plan

<Message type="tip">
  This guide focuses on managing your databases through the Scaleway console. For advanced configurations, you can access your [Web Hosting control panel](/webhosting/quickstart/#how-to-access-your-hosting-dashboard-from-the-scaleway-console).
</Message>

## Create a database

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
2. Click the domain name of the Web Hosting service you want to configure. The **Hosting information** page opens.
3. Click the **Databases** tab to display information about your databases.
4. Click **Create database** in the **Databases** section of the page. A dialog box appears.
5. Enter a name for the database, select an existing database user from the dropdown or create a new one by entering a username and password.
6. Click **Create database** to confirm.

## Create a database user

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
2. Click the domain name of the Web Hosting service you want to configure. The **Hosting information** page opens.
3. Click the **Databases** tab to display information about your databases.
4. Click **+ Create database user** in the **Databases users** section. A dialog box appears.
5. Enter a username and password.
6. Select an existing database from the dropdown, then click **Create database user**.

## Update the password of a database user

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
2. Click the domain name of the Web Hosting service you want to configure. The **Hosting information** page opens.
3. Click the **Databases** tab to display information about your databases.
4. Click <Icon name="more" />, then **Change password** next to the database user. A dialog box appears.
5. Enter your new password and click **Update database user** to update the password.

## Export a database

<Tabs>
  <TabsTab label="phpMyAdmin (MySQL) or phpPgAdmin (PostgreSQL)">
    <Message type="tip">
      Web Hosting Essential and Advanced plans include access to the cPanel dashboard.
    </Message>
    Export a MySQL or PostgreSQL database via cPanel dashboard.

    1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
    2. Click the domain name of the Web Hosting plan you want to configure. The **Overview** tab displays information about your Web Hosting, such as your credentials to access your hosting dashboard.
    3. Click **Open hosting dashboard** in the **Hosting information** section of the page. The cPanel or WordPress hosting dashboard opens in a new tab.
        <Message type="tip">
        Retrieve your username under **Main user name** in the **Hosting information** section and your password in the **Initial password** section.
        </Message>
    4. In the **Databases** section, click **phpMyAdmin** for a MySQL database or **phpPgAdmin** for a PostgreSQL database. You can also use **JetBackup** for a similar result. The tool opens in a new browser tab.
    5. Select the database you want to export from the menu on the left.
    6. Click the **Export** tab.
    7. Select **Quick** to export the entire database, or **Custom** to choose specific tables and options.
    8. Leave the format set to **SQL**, then click **Export**. Your browser downloads the database as a `.sql` file.
  </TabsTab>
  <TabsTab label="Command line">
    <Message type="tip">
      Web Hosting Essential and Advanced plans include access to the cPanel dashboard.
    </Message>
    Export a database using the `mysqldump` command line (Essential and Advanced plans only).

    1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
    2. Click the domain name of the Web Hosting plan you want to configure. The **Overview** tab displays information about your Web Hosting, such as your credentials to access your hosting dashboard.
    3. Click **Open hosting dashboard** in the **Hosting information** section of the page. The cPanel or WordPress hosting dashboard opens in a new tab.
        <Message type="tip">
        Retrieve your username under **Main user name** in the **Hosting information** section and your password in the **Initial password** section.
        </Message>
    4. In the **Advanced** section, click **Terminal**. The command-line interface appears.
    5. Run the following command, replace the placeholders with the appropriate values.
        ```bash
        mysqldump -u <database_user> -p <database_name> --no-tablespaces > backup.sql
        ```
    6. Enter your database password when prompted. The exported database is saved as `backup.sql` in the current directory.
  </TabsTab>
  <TabsTab label="WordPress plugin">
    Export a database using a WordPress plugin such as [WP-Database Backup](https://wordpress.org/plugins/wp-database-backup/) or [UpdraftPlus](https://wordpress.org/plugins/updraftplus/).

    1. Download and install the plugin of your choice from the WordPress plugin repository.
    2. Follow the plugin instructions to export your database.
  </TabsTab>
</Tabs>

## Delete a database user

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
2. Click the domain name of the Web Hosting service you want to configure. The **Hosting information** page opens.
3. Click the **Databases** tab to display information related to your databases.
4. Click <Icon name="more" />, then **Delete** next to the database user you want to delete. A dialog box appears.
5. Click **Delete database user** to delete the user.

## Delete a database

1. In the [Scaleway console](https://console.scaleway.com) side menu, go to **Domains & Web Hosting** > **Web Hosting**. The Web Hosting page opens.
2. Click the domain name of the Web Hosting service you want to configure. The **Hosting information** page opens.
3. Click the **Databases** tab to display information about your databases.
4. Click <Icon name="delete" /> next to the database you want to delete. A dialog box appears.
5. Click **Delete database** to delete the database.
