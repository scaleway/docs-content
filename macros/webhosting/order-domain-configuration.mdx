Choose one of the following options to define which domain you want to link to your Web Hosting.

<Tabs>
    <TabsTab label="Create and use a free Scaleway subdomain">
        This option allows you to create and access your Web Hosting service immediately, without needing to add a custom domain. You can later configure a custom domain via cPanel if you wish.

        1. Select **Use free Scaleway subdomain**.
        2. Enter a subdomain.
        3. Click the search icon to confirm.
        4. Click **Order Web Hosting**.
    </TabsTab>
    
    <TabsTab label="Use External domain">
        This option allows you to use your own external domain and skip the subdomain selection. A random subdomain will automatically be assigned in parallel to your custom domain. This ensures that your website remains accessible at all times via the assigned subdomain, even if your custom domain is not yet configured.

        1. Select **Use my own domain**.
        2. Select **External domain or register later**.
        3. Enter your **domain name** or the name of the domain you want to register. To register a domain, see the [Register an internal domain](/domains-and-dns/how-to/register-internal-domain/) page.
        4. Read the information banner about DNS records configuration.
        5. Click **Order Web Hosting**.
    </TabsTab>

    <TabsTab label="Use my own Scaleway domain">
        This option allows you to use your own Scaleway domain.

        1. Select **Use my own domain**.
        2. Select **Scaleway domain**.
        3. Select your Scaleway domain in the dropdown. If you have just registered your Scaleway domain and it does not appear in the dropdown, click **Reload list**.
        4. Check **Use a subdomain** if you want to use an existing subdomain or to create a new one.
            <Message type="tip">
                You can use a subdomain if you want to create a separate section of your website, such as a blog or a shop, when your main domain is dedicated to another purpose.
                For example, if your main website is `my-cookies.com`, you could use a subdomain like `recipes.my-cookies.com` to create a separate section for sharing cookie recipes, while keeping your main site focused on selling cookies.
            </Message>
        5. Enter an existing subdomain name, or a new name to create one.
        6. Choose between **Automatic DNS configuration** and **Advanced DNS configuration**.
        7. Click **Order Web Hosting**.
    </TabsTab>
</Tabs>
