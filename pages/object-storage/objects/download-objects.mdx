You can download objects from a bucket to your local file system from the [Scaleway console](https://console.scaleway.com), or with any Amazon S3-compatible tool. To share an object with other users instead, see [How to manage object visibility and sharing](/object-storage/access-control/object-visibility-and-sharing/).

Objects in the Glacier storage class must be [restored](/object-storage/storage-classes/restore-from-glacier/) before you can download them.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Object Storage bucket](/object-storage/buckets/create-a-bucket/) containing [objects](/object-storage/objects/upload-objects/)
- A CLI tool [installed and configured](/object-storage/api-clients/cli-tools-and-clients/), if you do not use the console

## Download an object

The following tabs describe how to download an object using the console or a CLI tool. The rclone, s3cmd, and MinIO Client examples use the `scaleway` remote and alias that [the Scaleway CLI generates](/object-storage/api-clients/scaleway-cli/). Replace the placeholders with the appropriate values.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of your bucket. The list of your objects appears.

    3. Click <Icon name="download" /> next to the object to download it to your local file system.
  </TabsTab>
  <TabsTab label="AWS CLI">
    Run the following command to download an object:

    ```bash
    aws s3 cp s3://<BUCKET_NAME>/<OBJECT_KEY> <DESTINATION_PATH>
    ```

    To download all the objects with a given prefix, add the `--recursive` option and use the prefix instead of the object key.
  </TabsTab>
  <TabsTab label="rclone">
    Run the following command to download an object:

    ```bash
    rclone copy scaleway:<BUCKET_NAME>/<OBJECT_KEY> <DESTINATION_PATH>
    ```
  </TabsTab>
  <TabsTab label="s3cmd">
    Run the following command to download an object:

    ```bash
    s3cmd get s3://<BUCKET_NAME>/<OBJECT_KEY> <DESTINATION_PATH>
    ```
  </TabsTab>
  <TabsTab label="MinIO Client">
    Run the following command to download an object:

    ```bash
    mc cp scaleway/<BUCKET_NAME>/<OBJECT_KEY> <DESTINATION_PATH>
    ```
  </TabsTab>
</Tabs>

The equivalent API call is [GetObject](/object-storage/api-clients/object-operations/#getobject).
