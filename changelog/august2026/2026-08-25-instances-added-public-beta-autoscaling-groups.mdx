Instance Autoscaling Groups is now available in Private Beta for the fr-par, nl-ams, and pl-waw regions.

This new feature enables automatic scaling and health management for standard Instance workloads based on resource consumption metrics, eliminating the need to containerize applications or manage complex orchestrators.
