---
title: FinOps API resource_id change
status: changed
date: 2026-10-26
category: billing
product: finops
---


The FinOps API now returns *server IDs* instead of *session IDs* for **Instance** products in the `resource_id` field.
This change takes effect on October 22, 2026, and therefore a mix of *session IDs* and *server IDs* might be present for the month of October 2026.
