[File Storage](https://www.scaleway.com/en/file-storage/)
 is now in General Availability in the AMS region.

For Kubernetes users, dynamically provision Persistent Volumes with ReadWriteMany access by referring to [this documentation page](https://www.scaleway.com/en/docs/kubernetes/how-to/use-sfs-with-kubernetes/).

For non Kubernetes users, attach multiple CPU or GPU instances to a shared and fully managed file system via the [Console, CLI](https://www.scaleway.com/en/docs/file-storage/quickstart/) or [Terraform](https://registry.terraform.io/providers/scaleway/scaleway/latest/docs/resources/file_filesystem).

To reach the ideal level of performance for your file system use cases, also refer to [performance scaling](https://www.scaleway.com/en/docs/file-storage/reference-content/performance-scaling/) and [compatible instance type selection](https://www.scaleway.com/en/docs/file-storage/reference-content/file-system-instance-selection/) recommendations.
