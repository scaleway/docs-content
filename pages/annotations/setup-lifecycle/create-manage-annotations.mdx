Learn how to create and manage annotation [keys](/annotations/concepts/glossary/#key) and [values](/annotations/concepts/glossary/#value) using the Scaleway console.

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/#owner) status or [IAM permissions](/iam/concepts/#permission) allowing you to perform actions in the intended Organization
- The [`AnnotationsFullAccess` permission set](/annotations/setup-lifecycle/configure-annotations-permissions/), which gives you full access to keys, values, and bindings

## Create an annotation key-value pair

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**.  The Annotations page opens.

2. Click the **Create annotation**. The **Create annotation** page opens.

3. Enter a name for your key, and optionally a description (to give a brief summary of the purpose or meaning of the key).
    - **Key Name**:
      - Must be a unique string without spaces
      - Maximum length: 128 characters
      - Allowed values: The key name must start with a letter or underscore (_), followed by letters, digits, or underscores. No spaces, hyphens, dots, or other special characters are allowed. The regex equivalent is: `^[_\\pL][_\\pL0-9]*$`
    - **Description**: 
      - Maximum length: 1024 characters
      - Allowed values: No restrictions

4. Enter a value, and optionally a description (to give a brief summary of the purpose or meaning of the value).
    - **Value Name**:
      - Maximum length: 256 characters
      - Allowed values: The value name must start with a letter or underscore (_), followed by letters, digits, or underscores. No spaces, hyphens, dots, or other special characters are allowed. The regex equivalent is: `^[_\\pL][_\\pL0-9]*$`
    - **Description**: 
      - Maximum length: 1024 characters
      - Allowed values: No restrictions

5. Enter more values if needed, using the **Add value** button.

6. Click **Create annotation**.

Once you have created an annotation, you can [bind it to one or more Scaleway resources](/annotations/setup-lifecycle/bind-and-detach-annotations).

## Manage keys

Once you already have some annotation keys in place, you may have to edit or delete an existing key.

### Edit a key

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your annotations appears.

2. Click <Icon name="more" /> next to the key you want to edit. Click **Edit key** in the menu. The **Edit key** dialog box appears.

    Alternatively, click the key that you want to edit. The overview page of the key opens. Click **Actions** and select **Edit key**. The **Edit key** dialog box appears.

3. Make your changes, then click **Update**.

### Delete a key

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your annotations appears.

2. Click <Icon name="more" /> next to the key you want to delete. Click **Delete key** in the menu.

    Alternatively, click the name of the key that you want to delete. The overview page of the key opens. Click **Actions** and select **Delete key**. 
    
    A confirmation dialog box appears.

3. *If the key has no associated value*, click **Delete**. Your key has now been deleted.

4. *If the key has some associated values and maybe even resources*, deleting the key will break those associations. You must [remove bindings](/annotations/setup-lifecycle/bind-and-detach-annotations/#detach-an-annotation-from-a-resource) and [delete values](#delete-a-value) first. After removing the bindings and values, you can come back and delete the key.

## Manage values

### Add a value for an existing annotation

Once you already have some annotations in place, you may want to add one or more values for an existing annotation key-value pair.

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**.  The list of your annotations appears.

2. Click the relevant key. On the overview page of the key, click the **Create value** button. The **Create value** dialog box appears.

    Alternatively, click <Icon name="more" /> next to the key for which you want to add a new value. Click **Add value for the key** in the menu. The **Create value** dialog box appears.

3. Enter a name for the value and optionally a description too (to give a brief summary of the purpose or meaning of the value).
    - **Value Name**:
      - Maximum length: 256 characters
      - Allowed values: The value name must start with a letter or underscore (_), followed by letters, digits, or underscores. No spaces, hyphens, dots, or other special characters are allowed. The regex equivalent is: `^[_\\pL][_\\pL0-9]*$`
    - **Description**: 
      - Maximum length: 1024 characters
      - Allowed values: No restrictions

4. Click **Create value**.

### Edit a value

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your annotations displays.

2. Click the relevant key. The overview page of the key opens. 

3. Click <Icon name="more" /> next to the value you want to edit. Click **Edit value** in the menu. The **Edit value** dialog box appears.

    Alternatively, click the name of the value that you want to edit. The overview page of the value opens. Click **Actions** and select **Edit value**. The **Edit value** dialog box appears.

4. Make your changes, then click **Save**.

### Delete a value

1. In the [console](https://console.scaleway.com/) side menu, go to **Management & Governance** > **Annotations**. The list of your annotations appears.

2. Click the relevant key. The overview page of the key opens. 

3. Click <Icon name="more" /> next to the value you want to edit. Click **Delete value** in the menu. A confirmation dialog box appears.

    Alternatively, click the value that you want to delete. The overview page of the value opens. Click **Actions** and select **Delete value**. A confirmation dialog box appears.

4. *If the value is not bound to any resource*, click **Delete**. Your value has now been deleted.

5. *If the value is bound to one or more resources*, you must [remove the binding](/annotations/setup-lifecycle/bind-and-detach-annotations/#detach-an-annotation-from-a-resource) first. After removing the associated resources, you can come back and delete the value.
