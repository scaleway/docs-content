This release upgrades the Kubernetes control plane and node components to version 1.37, including updated networking, storage, and observability components.

### Control plane & add-ons

- Calico: `v3.32.1`
- Cilium: `v1.20.1`
- Kilo: `0.7.0`
- Metrics Server: `v0.9.0`
- CoreDNS: `v1.14.7`
- Scaleway Block Storage CSI driver: `v0.3.6`
- Scaleway File Storage CSI driver: `v0.0.3`
- Cloud Controller Manager (CCM): `v0.36.2`

### Node changelog components

- Linux kernel: `6.8.0-136-generic`
- containerd: `2.3.4`
- CNI plugins: `1.9.1`
- runc: `1.5.1`

### Feature gates available in 1.37

The following feature gates are available and can be enabled as needed:

- `HPAScaleToZero`
- `CPUManagerPolicyAlphaOptions`
- `MutatingAdmissionPolicy`
- `ImageVolume`

For more information, refer to [Scaleway's Kubernetes version support policy](/kubernetes/reference-content/version-support-policy/).
