As part of our security measures, Scaleway is upgrading Web Hosting websites running on PHP 5.2, 5.4 and 5.5 **to PHP 5.6**.

This change may affect older websites, particularly those using outdated CMS versions, plugins, or custom PHP code.

<Message type="important">
    PHP 5.6 no longer receives official security updates. This migration is a transitional measure, and upgrading to a currently supported PHP version remains recommended.
</Message>

## Main compatibility changes

| Feature | Potential impact | Recommended action |
| :--- | :--- | :--- |
| MySQL functions | `mysql_*` functions are deprecated but still supported if the extension is enabled. | Migrate to MySQLi or PDO. |
| Deprecated functions | Functions such as `ereg()`, `split()` or `session_register()` may generate warnings or no longer work. | Replace outdated functions. |
| SSL/TLS connections | PHP 5.6 verifies SSL certificates by default, potentially breaking external connections. | Check HTTPS, SMTP and API integrations. |
| PHP configuration | Legacy settings such as `register_globals` and `magic_quotes_gpc` are no longer supported. | Review application configuration. |
| Legacy code | Older PHP scripts may behave differently or generate errors. | Check PHP logs and test critical features. |

## CMS and framework compatibility

If your website uses a CMS or framework, verify its compatibility with PHP 5.6.

|Platform | What to check |
| :--- | :--- |
| WordPress | WordPress version, plugins and themes |
| PrestaShop | Version compatibility, payment and shipping modules |
| Joomla! / Drupal | Core version, templates and extensions |
| Symfony / Other frameworks | Framework version and PHP dependencies |

Older versions may require updates before working correctly with PHP 5.6.

## What should you do?

After the migration:
    1. Check your website: verify that pages load correctly.
    2. Test key features: forms, authentication, payments, database access and emails.
    3. Review PHP error logs: look for fatal errors, warnings and deprecated functions.
    4. Update incompatible code, plugins or CMS components if necessary.

If you encounter hosting-related issues, contact [Scaleway Support](https://console.scaleway.com/support/create).
