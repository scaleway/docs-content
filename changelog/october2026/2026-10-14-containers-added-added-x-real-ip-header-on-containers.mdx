---
title: Added X-Real-IP header on Containers
status: added
date: 2026-10-14
category: serverless
product: containers
---

Use the `X-Real-IP` header to identify the IP address of the client. It contains the list of IP addresses the request has passed through, with the original client IP as the first entry.

For more informations [read dedicated documentation](/serverless-containers/reference-content/request-headers/).
