**IP** **A**ddress **M**anager (IPAM) is Scaleway's tool for planning, tracking and managing the IP address space of Scaleway products. It acts as a single source of truth for the IP addresses of Scaleway resources.

You can use IPAM in the Scaleway console to list the [public](/ipam/concepts/#public-flexible-ip-address) and [private IP addresses](/ipam/concepts/#private-ip-address) of all your Scaleway resources, and view and edit their additional information. You can also [reserve](/ipam/how-to/reserve-ip/) an address in advance, and release it when you no longer need it.

Every address in IPAM belongs to one of three **sources**:

- **Private IPs**: addresses on your Private Networks
- **Public zonal IPs**: public addresses scoped to a single Availability Zone, such as `fr-par-1`
- **Public regional IPs**: public addresses scoped to a whole region, such as `fr-par`

## How to list and filter your IP addresses

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Select the region whose IP addresses you want to list, using the drop-down menu at the top of the page.

3. Select the **source** of the addresses to display. For private IPs, select a **VPC** to display them. For public zonal IPs, select a **zone**. Public regional IPs display immediately.

    Addresses are listed here if they are reserved in IPAM. This means either:

    - You [reserved an address via IPAM](/ipam/how-to/reserve-ip/), or
    - You [attached a resource to a Private Network](/vpc/how-to/attach-resources-to-pn/): this triggers IPAM to reserve and attach a private IP address for the resource on the network.

    Addresses which are available but unreserved do not display in the list. For Private Networks, this means the full range of addresses in each [CIDR block](/vpc/concepts/#cidr-block) is not shown.

4. Refine the list using the other filters that display alongside the **Source** filter, such as **Private Network**, **IP type** ([IPv4](/ipam/concepts/#ipv4) or [IPv6](/ipam/concepts/#ipv6)), and whether the address is attached to a resource or simply reserved.

    Click **All filters** to display the full set of filters available for the selected source, or **Clear All** to reset them.

## How to view and edit the details of an IP address

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Use the **Source** filter, and the other filters that display alongside it, to find the IP address you want to view.

3. Click the <Icon name="more" /> icon next to the IP address whose details you want to view, then click **More info**.

    The details of your IP address appear:
    - The IP address
    - The **source** of the IP address, and its scope: the Private Network for a private IP, the Availability Zone for a public zonal IP, or the region for a public regional IP
    - Which **resource** (if any) it is attached to
    - The **ID** of the IP address
    - The date on which the IP was **created**. This corresponds to the date it was reserved in IPAM, either through a manual reservation or when it was attached to a resource.
    - The date on which the IP was last **updated**
    - The **tags** associated with the IP address. You can edit these tags if you wish.

4. Click **OK** to exit the screen.

## How to reserve an IP address

1. Click **IPAM** in the **Network** section of the [Scaleway console](https://console.scaleway.com) side menu.

2. Select the region in which you want to reserve an IP address, using the drop-down menu at the top of the page.

3. Click **Reserve IP**. The IP reservation menu appears.

4. Select the **source** of the IP address to reserve: **Private IPs**, **Public zonal IPs**, or **Public regional IPs**.

5. Define the remaining parameters, which depend on the source you selected:

    - For a private IP: the **VPC** and the **Private Network** to reserve the address from. The reserved IP comes from the [CIDR block](/vpc/concepts/#cidr-block) of this network, and is available to attach resources to it.
    - For a public zonal IP: the **Availability Zone** to reserve the address in.
    - For a public regional IP: no further scope is required, as the address is available across the whole selected region.

6. Select the **IP type**: **IPv4** or **IPv6**, and optionally add **tags** to help you filter and manage your reserved IPs later.

    <Message type="tip">
    Four IP addresses from each Private Network CIDR block are unavailable for reservation: the first two and last two in the block. For example, for the subnet `172.16.12.0/22` the following addresses cannot be reserved or assigned to any resource: `172.16.12.0`, `172.16.12.1`, `172.16.15.254` and `172.16.15.255`.
    </Message>

7. Check the **estimated cost**, then click **Reserve** to reserve the IP.

    The IP address is reserved, and displays in the list with the **Reserved** status.

You can now [attach a resource using this address](/ipam/how-to/attach-resource/), or, if and when you no longer need it, [release it](/ipam/how-to/release-ip/).
