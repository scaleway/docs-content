A Scaleway Resource Name (SRN) is a Uniform Resource Identifier (URI) that uniquely identifies a Scaleway resource. 

In the context of Annotations, you are required to provide an SRN when attaching a key-value pair to a selected cloud resource via the Annotations API.

An SRN follows this format:

```
srn://product-slug.partition/locality-type/{locality}/resource-type/{resource-id}
```

Examples:

```
# Key Manager key - an example with locality
srn://key-manager.scw.eu/regions/fr-par/keys/25f6c309-a2c6-4fb2-8d16-57960c3fb9df

# IAM application - an example with no locality
srn://iam.scw.eu/applications/25f6c309-a2c6-4fb2-8d16-57960c3fb9df
```

The following table explains how to compose an SRN:

| SRN segment   | Details                                                                                                                                                                                                                                                                                                                                   |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| srn://        | Specifies that the string that follows is a Scaleway Resource Name (SRN).                                                                                                                                                                                                                                                                 |
| product-slug  | An identifier for the product.<br /> Examples: `block` for Block Storage, `secret-manager` for Secret Manager                                                                                                                                                                                                                             |
| partition     | The identifier of the Scaleway partition represented as a domain.<br /> Possible values (exhaustive list): `scw.eu`                                                                                                                                                                                                                       |
| locality-type | The locality type.<br /> Possible values (exhaustive list): `regions`, `zones`                                                                                                                                                                                                                                                            |
| locality      | The Scaleway region code or zone code.<br />Resources with locality will include the locality in a parent segment.<br /> Resources without locality have no locality-type nor locality segment.<br /> Examples for region: `fr-par`, `nl-ams`, `pl-waw`, `it-mil`<br /> Examples for zone: `fr-par-1`, `nl-ams-2`, `pl-waw-3`, `it-mil-1` |
| resource-type | The resource type in its plural form, similar to a REST segment for a resource.<br /> Examples: `routes` for VPC routes, `volumes` for Block volumes                                                                                                                                                                                      |
| resource-id   | The unique identifier of the resource. <br /> You can retrieve this information from the resource's page in the Scaleway console or via the product's API.                                                                                                                                                                                |

For a complete list of SRNs, see [Resource types and their SRNs](#resource-types-and-their-srns).

For a complete list of product-slugs, see [Product slugs](#product-slugs).

Note that **Object Storage resources are special**:

- The bucket and object resource IDs are user-set and unique by partition.
- The object resource ID is a path inside the bucket.

As a result, the path will be split in two segments: the bucket and the object.

```
srn://object.scw.eu/buckets/bucket-name
srn://object.scw.eu/buckets/bucket-name/objects/path/to/my/object
```

Note that some **nested resources** rely on a parent UUID and a user-set ID in order to be addressed (e.g., a secret version). In this scenario, the nearest parent with a UUID will be included in the SRN.

Example:

```
srn://secret-manager.scw.eu/regions/fr-par/secrets/25f6c309-a2c6-4fb2-8d16-57960c3fb9df/versions/5
```
