### Breaking

AvailableContainerRuntimes has been removed from methods `GetVersion`, `ListClusterAvailableVersions`, and `ListVersions`.

### Changed

- The IAM application-id of the control plane is now visible.
- This release introduces new patch versions for Kubernetes 1.35.9, 1.36.5, and 1.37.1.

These versions contain the following dependencies:

#### Control plane & add-ons
- Kubernetes 1.37.1: Calico `v3.32.2`
- Kubernetes 1.36.5: Calico `v3.32.2` and Cilium `v1.19.8`
- Kubernetes 1.35.9: Cilium `v1.18.14` and CSI External provisioner `v6.2.1`

#### Node changelog components
- Kubernetes 1.37.1: containerd `2.3.6` and runc `1.5.2`
- Kubernetes 1.36.5: runc `1.4.3`
- Kubernetes 1.35.9: containerd `2.2.9` and runc `1.4.3`
