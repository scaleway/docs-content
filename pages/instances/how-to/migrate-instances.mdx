You can migrate your data from one Instance to another, for example to move to a more powerful offer type. To migrate an Instance, you create an image of the Instance, create a new Instance from this image, and move the flexible IP address to the new Instance.

See [How to choose the right Instance type](/instances/reference-content/choosing-instance-type/) for more information about choosing the right offer type for your use case.

<Requirements />
- A Scaleway account logged in to the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [SSH key](/iam/security/create-ssh-key/)
- An [Instance](/instances/how-to/create-an-instance/)

## Create an image of the Instance

<Message type="important">
  Images do not include [scratch storage](/instances/reference-content/understanding-scratch-storage/). If your Instance uses scratch volumes, copy any data you need to keep to a Block Storage volume or an Object Storage bucket before you create the image.
</Message>
[Create an image](/instances/how-to/create-a-backup/#how-to-create-an-image) of the Instance you want to migrate.

## Create a new Instance from the image

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the Instance you created an image of. The **Overview** page of the Instance opens.
4. Click the **Images** tab.
5. Click <Icon name="more" /> next to the image of the Instance.
6. Click **Create Instance from image**. The Instance creation wizard opens, with the image preselected.
7. Select an offer type that uses the same CPU architecture as the original Instance (for example, x86 to x86, or ARM to ARM).
8. Click **Advanced options**.
9. Use the <Icon name="toggle" /> toggle to disable **flexible IP**. You move the flexible IP address of the original Instance to the new Instance in the next section.
10. Finish configuring the Instance according to your requirements.
11. Click **Create Instance**. The new Instance appears in the list of your Instances.

## Move the flexible IP address to the new Instance

1. In the Scaleway console side menu, go to **Compute** > **CPU & GPU Instances**. The [Instances dashboard](https://console.scaleway.com/instance/servers) opens.
2. Select the Availability Zone (AZ) from the dropdown (e.g., `PAR1`) to view resources in the selected AZ.
3. Click the **Flexible IPs** tab.
4. Click <Icon name="more" /> next to the [flexible IP address](/instances/concepts/#flexible-ip) of the original Instance.
5. Click **Switch Instance**. A dialog box appears.
6. Select the new Instance from the dropdown.
7. Click **Attach flexible IP to Instance**. The new Instance is reachable through the flexible IP address of the original Instance.

## Delete the original Instance

If you no longer need the original Instance, you can [delete it](/instances/how-to/delete-instance/).
