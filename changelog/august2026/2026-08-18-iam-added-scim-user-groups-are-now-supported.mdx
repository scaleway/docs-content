status: added
date: 2026-08-18

---

SCIM user provisioning now support user groups.

Note 1 :  If you are on Entra ID, activate groupe provisioning by going to `Attribute Mapping` in the `Manage` menu, select `Provision Microsoft Entra ID Groups`, and select `Yes` on `Enabled`.

Note 2 : Nested groups aren't supported.
