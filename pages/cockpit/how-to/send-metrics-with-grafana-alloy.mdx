The Grafana Alloy agent is a component used in observability and monitoring setups, to collect and send metrics, logs, and traces from your applications, services, and infrastructure to observability platforms, such as Cockpit.

This page shows you how to configure the Grafana Alloy agent to push your metrics and logs from a [Scaleway Instance](/instances/concepts/#instance) and visualize them in Grafana. You can also use this tutorial to **push your data from Scaleway resources or external/custom resources**.

For the sake of this documentation, we are using Grafana Alloy on Linux. Refer to the [official Grafana documentation](https://grafana.com/docs/alloy/latest/get-started/) to find the commands to use depending on your operating system of choice.

<Requirements />

  - [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
  - A Scaleway account logged into the [console](https://console.scaleway.com)
  - [Created a custom data source of the metrics type](/cockpit/how-to/create-external-data-sources/)
  - [Created a custom data source of the logs type](/cockpit/how-to/create-external-data-sources/)
  - A [token](/cockpit/how-to/create-token/) with push permissions for metrics in the **same region as your metrics**

<Message type="important">
 - Using default agent settings may collect unnecessary metrics, driving up resource consumption and your monthly bill.

 - Sending metrics and logs for Scaleway resources or personal data using an external path is a billable feature. In addition, any data that you push yourself is billed, even if you send data from Scaleway products. See the [product pricing](https://www.scaleway.com/en/pricing/managed-services/#cockpit) for more information.
</Message>

## Create your Instance and install Grafana Alloy

1. [Create an Instance](/instances/how-to/create-an-instance/) from the **Compute** section of the Scaleway console.
2. Copy the public IP your Instance as you will need it in the next steps.
3. Open a terminal and type the following command to connect to your Instance:

            ```bash
            ssh root@<your Instance public IP>
            ```   
4. [Install Grafana Alloy](https://grafana.com/docs/alloy/latest/get-started/install/) on the Instance.                     

## Configure Grafana Alloy on the Instance to send metrics to Prometheus

1. Create a folder named `config` on the Instance.
2. Create a file named `cockpit.alloy` inside the `config` folder.
3. Paste the following template inside `cockpit.alloy`:
        ```
        prometheus.exporter.unix "node" {
            set_collectors = [
                "uname",
                "cpu",
                "cpufreq",
                "loadavg",
                "meminfo",
                "filesystem",
                "netdev",
            ]
        }

        prometheus.scrape "node" {
            scrape_interval = "60s"
            scrape_timeout  = "4s"

            targets    = prometheus.exporter.unix.node.targets
            forward_to = [prometheus.remote_write.cockpit.receiver]
        }

        prometheus.remote_write "cockpit" {
            endpoint {
                url = "https://xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.metrics.cockpit.<region>.scw.cloud/api/v1/push"
                headers = {
                    "X-TOKEN" = "COCKPIT_TOKEN_SECRET_KEY",
                }
            }
        }
        ```
4. Replace `https://xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.metrics.cockpit.<region>.scw.cloud/api/v1/push` with your metrics URL. You can retrieve it from the Scaleway console > **Monitoring** > **Cockpit** >[**Data sources** tab](https://console.scaleway.com/cockpit/dataSource).
5. Replace `COCKPIT_TOKEN_SECRET_KEY` with the secret key of your Cockpit token, then save your changes.
        <Message type="important">
          Make sure that your token and your metrics data source were both created in the same region.
        </Message>
6. Open a terminal and [start Alloy](https://grafana.com/docs/alloy/latest/get-started/run/):
        ```
        alloy
        ```
7. In the same terminal, run the following command.
        ```
        alloy run config/cockpit.alloy
        ```
        The two last lines of your output should look similar to the following.
        ```
        ts=2026-01-23T14:23:05.542081Z level=info msg="now listening for http traffic" service=http addr=127.0.0.1:12345
        ts=2026-01-23T14:23:13.432896Z level=info msg="Done replaying WAL" component_path=/ component_id=prometheus.remote_write.cockpit subcomponent=rw remote_name=aa0551 url=https://xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.metrics.cockpit.fr-par.scw.cloud/api/v1/push duration=12.900498616s
        ```

## Visualizing your metrics

1. In the [console](https://console.scaleway.com/) side menu, click **Monitoring** > **Cockpit**. The **Cockpit** overview page opens.
2. Click **Access Grafana** to open your preconfigured dashboards in Grafana. You are redirected to the Grafana website.
3. Log in to your Grafana account. The Grafana overview page opens.
4. Click **Dashboards**, then click the **New** side menu. A dropdown displays.
5. Click **Import** to import a dashboard.
6. In the **Find and import dashboards for common applications at grafana.com/dashboards** field, enter `1860`, then click **Load**.

    <Message type="note">
      `1860` is the ID of the [Node Exporter Full dashboard](https://grafana.com/grafana/dashboards/1860-node-exporter-full/) provided by Grafana.
    </Message>

7. Enter a name for your dashboard or use the default name.
8. In the **Folder** field, select a folder in which to store your dashboard.
9. Click **Import**. Your dashboard should load and open.
10. In the dropdown next to **Datasource**, select the data source of your metrics. By default, your dashboard retrieves the data of your data source from the last 24 hours.
    <Lightbox image={AlloyDatasource} alt="A screenshot showing the imported dashboard with the Datasource field and a dropdown of available datasources." />
11. If your data source was created less than 24 hours ago, click the clock icon and adjust the time range to match its creation time.

    Your dashboard should look similar to the one in the following image.

    <Lightbox image={AlloyDashboard} alt="A screenshot showing the imported dashboard, which displays metrics such as: CPU usage, network traffic, disk space usage." />

## Configure Grafana Alloy on the Instance to send logs to Loki

1. Go to the `config/cockpit.alloy` file on the Instance (created when you set the Instance up for metrics collection).
2. Paste the following template inside `cockpit.alloy`:
        ```
        local.file_match "local_files" {
            path_targets = [{"__path__" = "/var/log/*.log"}]
            sync_period = "5s"
        }

        loki.source.file "log_scrape" {
            targets    = local.file_match.local_files.targets
            forward_to = [loki.process.filter_logs.receiver]
            tail_from_end = true
            }

        loki.process "filter_logs" {
            stage.drop {
                source = ""
                expression  = ".*Connection closed by authenticating user root"
                drop_counter_reason = "noisy"
            }
            forward_to = [loki.write.grafana_loki.receiver]
            }

        loki.write "grafana_loki" {
            endpoint {
                url = "https://xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.logs.cockpit.<region>.scw.cloud/api/v1/push"
            }
        }            
        ```
4. Replace `https://xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx.logs.cockpit.<region>.scw.cloud/api/v1/push` with your logs URL. You can retrieve it from the Scaleway console > **Monitoring** > **Cockpit** >[**Data sources** tab](https://console.scaleway.com/cockpit/dataSource).
5. Replace `COCKPIT_TOKEN_SECRET_KEY` with the secret key of your Cockpit token, then save your changes.
        <Message type="important">
          Make sure that your token and your logs data source were both created in the same region.
        </Message>
6. Open a terminal and [start Alloy](https://grafana.com/docs/alloy/latest/get-started/run/):
        ```
        alloy
        ```
7. In the same terminal, run the following command.
        ```
        alloy run config/cockpit.alloy
        ```
        The two last lines of your output should look similar to the following.
        ```
        ts=2026-10-12T12:24:19.223570135Z level=info msg="start tailing file" component_path=/ component_id=loki.source.file.log_scrape component=tailer path=/var/log/dpkg.log
        ts=2026-10-12T12:24:19.223825237Z level=info msg="start tailing file" component_path=/ component_id=loki.source.file.log_scrape component=tailer path=/var/log/kern.log
        ```
