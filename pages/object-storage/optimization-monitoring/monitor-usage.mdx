Object Storage is fully integrated with [Scaleway Cockpit](/cockpit/quickstart/), and automatically sends metrics and logs for each bucket. Use them to monitor your objects, storage usage, bandwidth, and requests. Cockpit is available for Object Storage in all [regions](/object-storage/concepts/glossary/#region-and-availability-zone).

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Object Storage bucket](/object-storage/buckets/create-a-bucket/)

<CockpitIamPermissions />

## View your metrics and logs

Cockpit is enabled by default if you have created [Scaleway resources integrated with Cockpit](/cockpit/reference-content/cockpit-product-integration/).

The **Metrics** and **Logs** tabs of a bucket in the console display its Object Storage metrics and logs. To explore them in Grafana:

1. On the [Cockpit overview page](https://console.scaleway.com/cockpit/overview) of the Scaleway console, click **Access Grafana**.

2. Log in to Grafana. The Scaleway Cockpit dashboard homepage opens.

3. In the Grafana side menu, click **Dashboards**, then open the **Scaleway** folder.

4. Click one of the following dashboards:
    - **Object Storage Overview** to view your metrics
    - **Object Storage Logs Overview** to view your logs

    The dashboard opens. Use the filters at the top of the page to refine your metrics and logs.

## Metrics collected by Cockpit

Cockpit collects the following metrics for each bucket. Each metric includes a `resource-id` label that identifies the bucket it originates from.

| Metric name | Description | Unit | Refresh frequency |
|---|---|---|---|
| `object_storage_bucket_objects_total` | Total number of objects stored in the bucket | Objects | 1 hour |
| `object_storage_bucket_usage_bytes_total` | Total storage space used by all objects in the bucket | Bytes | 1 hour |
| `object_storage_bucket_parts_total` | Total number of multipart upload parts in the bucket | Parts | 1 hour |
| `object_storage_bucket_bandwidth_egress_bytes` | Bytes sent from the bucket to clients (outbound traffic) | KB/MB per day | 1 minute |
| `object_storage_bucket_bandwidth_ingress_bytes` | Bytes received by the bucket from clients (inbound traffic) | KB/MB per day | 1 minute |
| `object_storage_bucket_http_response_time_seconds_bucket` | Distribution of HTTP response times for bucket operations | s/ms | 1 minute |
| `object_storage_bucket_http_response_time_seconds_count` | Total count of HTTP responses for bucket operations | min/s/ms | 1 minute |
| `object_storage_bucket_http_response_time_seconds_sum` | Cumulative sum of HTTP response times for bucket operations | s/ms | 1 minute |

## Logs collected by Cockpit

Cockpit collects the following fields for each request that a bucket receives:

| Field | Description |
|---|---|
| `@timestamp` | Time when the log entry was recorded |
| `s3_call` | Amazon S3 API operation performed (e.g., `GetObject`, `PutObject`) |
| `project_id` | ID of the Project associated with the request |
| `URI` | URI path of the HTTP request made to the bucket |
| `http_method` | HTTP method of the request (e.g., `GET`, `PUT`, `DELETE`) |
| `http_status_code` | HTTP status code returned in response to the request |
| `http_host` | Value of the HTTP `Host` header of the request |
| `bucket` | Name of the bucket targeted by the request |
| `txid` | Unique transaction ID of the request |
| `source_ip` | Source IP address of the request |
