You can delete objects from a bucket from the [Scaleway console](https://console.scaleway.com), or with any Amazon S3-compatible tool.

If [versioning](/object-storage/data-protection/versioning/) is enabled on the bucket, deleting an object creates a delete marker, and Object Storage keeps the previous versions of the object. You are billed for these versions until you delete them. To delete objects and their versions automatically, use [lifecycle rules](/object-storage/storage-classes/lifecycle-rules/).

<Requirements />

- A Scaleway account logged into the [console](https://console.scaleway.com)
- [Owner](/iam/concepts/glossary/#owner) status or [IAM permissions](/iam/concepts/glossary/#permission) allowing you to perform actions in the intended Organization
- An [Object Storage bucket](/object-storage/buckets/create-a-bucket/) containing [objects](/object-storage/objects/upload-objects/)
- A CLI tool [installed and configured](/object-storage/api-clients/cli-tools-and-clients/), if you do not use the console

## Delete an object

<Message type="important">
On a bucket without versioning, deleting an object is permanent and irreversible.
</Message>

The following tabs describe how to delete an object using the console or a CLI tool. The rclone, s3cmd, and MinIO Client examples use the `scaleway` remote and alias that [the Scaleway CLI generates](/object-storage/api-clients/scaleway-cli/). Replace the placeholders with the appropriate values.

<Tabs>
  <TabsTab label="Console">
    1. In the Scaleway console side menu, under **Storage**, click **Object Storage**. The list of your buckets appears.

    2. Click the name of the bucket that contains the object. The list of the objects of the bucket appears.

    3. Click <Icon name="more" /> next to the object, then click **Delete**. A dialog box appears.

    4. Click **Delete file** to confirm.
  </TabsTab>
  <TabsTab label="AWS CLI">
    1. Run the following command to delete an object:
        ```bash
        aws s3 rm s3://<BUCKET_NAME>/<OBJECT_KEY>
        ```

    2. Run the following command to check that the object no longer appears in the bucket:
        ```bash
        aws s3 ls s3://<BUCKET_NAME>
        ```
  </TabsTab>
  <TabsTab label="rclone">
    1. Run the following command to delete an object:
        ```bash
        rclone delete scaleway:<BUCKET_NAME>/<OBJECT_KEY>
        ```

    2. Run the following command to check that the object no longer appears in the bucket:
        ```bash
        rclone ls scaleway:<BUCKET_NAME>
        ```
  </TabsTab>
  <TabsTab label="s3cmd">
    1. Run the following command to delete an object:
        ```bash
        s3cmd del s3://<BUCKET_NAME>/<OBJECT_KEY>
        ```

    2. Run the following command to check that the object no longer appears in the bucket:
        ```bash
        s3cmd ls s3://<BUCKET_NAME>
        ```
  </TabsTab>
  <TabsTab label="MinIO Client">
    1. Run the following command to delete an object:
        ```bash
        mc rm scaleway/<BUCKET_NAME>/<OBJECT_KEY>
        ```

    2. Run the following command to check that the object no longer appears in the bucket:
        ```bash
        mc ls scaleway/<BUCKET_NAME>
        ```
  </TabsTab>
</Tabs>

The equivalent API calls are [DeleteObject](/object-storage/api-clients/object-operations/#deleteobject) and [DeleteObjects](/object-storage/api-clients/object-operations/#deleteobjects).

If you cannot delete an object, or if deleted objects are still billed, see [I cannot delete my data or I am billed for objects I cannot see](/object-storage/troubleshooting/deletion-and-billing/).
